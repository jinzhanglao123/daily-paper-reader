## 摘要
离线目标条件强化学习（GCRL）旨在完全从固定轨迹数据中学习到达多样目标的策略。长时程离线 GCRL 仍然具有挑战性，因为稀疏的到达目标信号必须经过许多步传播，而执行错误无法通过额外的环境交互加以纠正。现有方法通过改进长程价值估计，或通过子目标、选项和动作块来缩短有效决策视野，以应对这些挑战。然而，在一些分层方法中，所选子目标只规定了要去哪里，而中间的状态空间路径仍隐含在以终点为条件的低层策略中。为了解决这一接口问题，我们提出 PathBridger，一种分层离线 GCRL 方法，显式地将子目标选择与短时程执行连接起来。PathBridger 构建一条通向所选中间端点的状态空间桥，并利用逆动力学模型将其解码为短的可执行动作块。在评估的 OGBench 任务上的实验表明其具有强劲的综合性能，尤其是在多物体 Cube 操作任务上增益显著。代码：https://github.com/SChoish/PathBridger

## Abstract
Offline goal-conditioned reinforcement learning (GCRL) aims to learn policies for reaching diverse goals entirely from fixed trajectory data. Long-horizon offline GCRL remains challenging because sparse goal-reaching signals must be propagated over many steps, while execution errors cannot be corrected through additional environment interaction. Existing methods address these challenges by improving long-range value estimation or reducing the effective decision horizon through subgoals, options, and action chunks. In several hierarchical methods, however, a selected subgoal specifies where to go, while the intervening state-space path remains implicit in an endpoint-conditioned low-level policy. To address this interface, we propose PathBridger, a hierarchical offline GCRL method that explicitly connects subgoal selection to short-horizon execution. PathBridger constructs a state-space bridge toward the selected intermediate endpoint and decodes it into a short executable action chunk using an inverse dynamics model. Experiments across the evaluated OGBench tasks demonstrate strong aggregate performance, with particularly large gains on the multi-object Cube manipulation tasks.
