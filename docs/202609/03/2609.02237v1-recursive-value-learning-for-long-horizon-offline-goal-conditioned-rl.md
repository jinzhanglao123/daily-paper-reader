## 摘要
将离线目标条件强化学习（GCRL）扩展到长时程任务很困难，因为（1）长程价值学习依赖于可能仍不准确的短程估计，并且（2）基于最大值的价值备份会通过重复传播放大高估。我们提出 DCRL（分治强化学习），它将每个轨迹片段递归分解为平衡二叉树，并从叶到根训练价值。因此，每个父节点仅在其子节点之后更新，使用所观测路径的精确分解，而非在噪声备选之间进行选择。由于该目标沿着不一定最优的示范路径学习价值，DCRL 跨轨迹联合传播价值以发现更短路径。得益于平衡二叉树，DCRL 将最坏情况的自举深度从线性降低到对数，这种更短的依赖结构在经验上对应着更慢的误差累积。在各种目标到达任务中，DCRL 显著优于先前的扁平离线 GCRL 方法，并且在五个最具挑战性的长时程 OGBench 任务上，它将先前最佳平均得分从 55 提高到 64，超过了所有扁平和分层基线。

## Abstract
Scaling offline goal-conditioned reinforcement learning (GCRL) to long-horizon tasks is difficult because (1) long-range value learning depends on shorter-range estimates that may still be inaccurate, and (2) max-based value backups can amplify overestimation through repeated propagation. We propose DCRL (Divide-and-Conquer RL), which recursively decomposes each trajectory segment into a balanced binary tree and trains the values from leaves to root. Each parent is therefore updated only after its children, using an exact factorization of the observed route rather than selecting among noisy alternatives. Since this objective learns values along demonstrated routes that are not necessarily optimal, DCRL jointly propagates values across trajectories to discover shorter routes. Thanks to the balanced binary tree, DCRL reduces worst-case bootstrap depth from linear to logarithmic, and this shorter dependency structure empirically corresponds to much slower error accumulation. Across diverse goal-reaching tasks, DCRL substantially outperforms prior flat offline GCRL methods, and on the five most challenging long-horizon OGBench tasks, it improves the best prior average score from 55 to 64, surpassing all flat and hierarchical baselines.

## 1. 论文的核心问题与整体含义

- **研究背景与动机**：离线目标条件强化学习（Offline GCRL）旨在从固定数据集中学习能够从任意状态到达指定目标的最优策略。将其扩展到长时程任务时面临两大困难：
  1. **长程价值依赖不可靠的短程估计**：长时程价值函数需要以短时程价值估计作为自举目标，但这些短程估计本身可能仍在训练中、并不准确。
  2. **基于最大值的备份会放大大高估**：标准贝尔曼式或传递式备份会在动作或中间状态上取最大值，在有限离线数据下，这种选择容易偏向被高估的候选，并在反复传播中累积误差。
- **整体含义**：论文提出 **DCRL（Divide-and-Conquer RL，分治强化学习）**，通过递归地将轨迹段分解为平衡二叉树，并按照从叶到根的顺序训练价值函数，显式利用“长段价值由短段价值构成”的依赖结构，从而将最坏情况下的自举深度从线性降低到对数，显著减缓误差累积。

## 2. 论文提出的方法论

### 2.1 核心思想：递归分治价值学习

- 对于一条轨迹中的片段 \((s_i, s_j)\)（\(i<j\)），DCRL 递归地在中点 \(k=\lfloor(i+j)/2\rfloor\) 处将其二分，直到到达单步叶子节点（如 \((s_i, s_{i+1})\)）。这样形成一个**平衡二叉树**。
- **训练顺序**：从叶子到根。单步叶子的价值被固定为 \(V(s_i, s_{i+1}) = \gamma\)（\(\gamma\) 为折扣因子）；父节点只在两个子节点训练完成后更新。
- 对于任意中间状态 \(w\)，行为价值满足精确分解：
  \[
  V_\tau(s,g) = V_\tau(s,w) \cdot V_\tau(w,g)
  \]
  与最大化备份不同，DCRL 使用**固定中点**而不进行噪声候选选择，从而避免选择导致的高估传播。

### 2.2 两个互补目标

DCRL 联合训练一个动作价值函数 \(Q(s,a,g)\)，同时优化两个损失：

1. **分治损失 \(\mathcal{L}_{\text{dc}}\)**（学习行为价值）：
   \[
   \mathcal{L}_{\text{dc}}(Q) = \mathbb{E}_{\tau_{\text{DC}}\sim\mathcal{T}} \left[ \mathcal{L}_{\text{BCE}}\left( Q(s_i,a_i,s_j),\; \text{sg}[Q(s_i,a_i,s_k)] \cdot \bar{Q}(s_k,a_k,s_j) \right) \right]
   \]
   其中 \(k\) 为中点，\(\text{sg}\) 表示停止梯度，\(\bar{Q}\) 为目标网络（EMA）。若某子段为单步，则其价值替换为 \(\gamma\)。使用普通 BCE 损失（期望分位数 \(\kappa_{\text{dc}}=0.5\)）。

2. **传播损失 \(\mathcal{L}_{\text{prop}}\)**（恢复最优价值）：
   \[
   \mathcal{L}_{\text{prop}}(Q) = \mathbb{E}_{\tau_{\text{prop}}\sim\mathcal{D}} \left[ \mathcal{L}^{\kappa_{\text{prop}}}_{\text{BCE}}\left( Q(s_i,a_i,g),\; \gamma^n \cdot \bar{Q}(s_{i+n},a_{i+n},g) \right) \right]
   \]
   目标 \(g\) 可为未来、随机或当前状态，通过全局重标记采样。使用上期望分位数 BCE（\(\kappa_{\text{prop}}=0.7\)）以偏好更短路径。

### 2.3 并行槽调度（Slot Scheduling）

- 为高效执行递归训练，维护 \(S\) 个独立槽（默认 \(S=128\)，批次大小为 1024）。每个槽保存一棵递归树的样本，按从叶到根的顺序排列。
- 每次更新时，随机选择一个槽并弹出其下一个样本；槽耗尽后重新采样新轨迹段生成新树。
- 由于各槽独立地排空和重新填充，它们逐渐失去同步，使每个批次中混合了不同长度的样本，同时保持每个槽内部的父子顺序。

### 2.4 理论性质

- **自举深度**：DCRL 将最坏情况自举深度从 TD-n 的 \(\Theta(H/n)\) 降低到 \(\Theta(\log_2(H/n))\)，其中 \(H\) 为轨迹长度，\(n\) 为传播步数。
- **子最优性分解**：论文证明（Property 1）对于行为距离 \(d_\tau\) 和最优距离 \(d^*\)，路线子最优性 \(e(s,g)=d_\tau(s,g)-d^*(s,g)\) 满足：
  \[
  e(s,g) \ge e(s,w) + e(w,g)
  \]
  即父路线的子最优性至少等于两个子路线的子最优性之和，这为“先学习短段、再学习长段”提供了理论依据。

## 6. 论文的主要结论与发现

- DCRL 在五个最具挑战性的长时程 OGBench 任务上将先前最佳平均分从 **55 提高到 64**，超过所有扁平和分层基线。

- 在 CALVIN 上，DCRL 是唯一能够连续完成全部四个子任务的扁平方法（状态输入完成率 8.5%，像素输入 1%）。
- 当传播水平 \(n \ge 25\) 时，DCRL-n 在三个长时程任务上一致优于 TD-n 和 TRL-n。
- 在 combination-lock 诊断实验中，DCRL-n 的 Q 误差随任务水平 \(H\) 增长最慢，验证了对数自举深度带来的误差累积优势。
- 消融显示：移除递归或传播均导致显著性能下降；最大备份不如精确因子分解；随机分裂性能不变但吞吐量降低；逆序训练严重损害性能。

- **理论基础扎实**：将分治递归与自举深度形式化联系，给出对数深度证明，并配套误差累积实证。
- **方法简洁有效**：固定中点分解避免了最大化选择偏差，同时保留并行槽调度以维持训练多样性。
- **互补目标设计**：分治目标学习可靠行为价值，传播目标恢复最优价值，分工明确。
- **实验全面客观**：覆盖多个基准、多种模态、多个方法家族，消融详尽，公平性控制良好。
- **性能提升显著**：在长时程任务上大幅超越现有方法，尤其是作为扁平方法达到了分层方法难以企及的性能。

## 8. 不足与局限

- **假设确定性动态**：精确因子分解要求环境确定性；在随机动态下，期望的乘积不等于乘积的期望，方法可能失效。
- **任务类型局限**：在 cube 操作任务上，分层方法（如 SHARSA）仍优于 DCRL，说明 DCRL 的优势并非适用于所有长时程任务，某些困难可能源于其他因素（如组合复杂度）。
- **传播水平 \(n\) 需手动调节**：不同任务需要不同的 \(n\)（例如 humanoidmaze/puzzle 用 \(n=100\)，cube 用 \(n=25\)），这增加了实际部署的调参负担。
- **计算开销**：槽调度引入 CPU 开销，吞吐量略低于 TRL（约低 24%）。
- **算力信息不完整**：未报告 GPU 数量、总训练时长等算力细节

- 6. **对数据规模与质量的依赖**：DCRL 在 100M–1B 级别的离线数据集上验证有效，但递归分治依赖叶子节点单步价值的可靠估计；在数据规模更小、轨迹质量更差或噪声更强的场景下，早期训练阶段的叶节点误差可能被放大，论文未系统探索低数据或低质量数据集下的表现。
- 7. **实现复杂度与调参负担**：除传播水平 \(n\) 需要手动调节外，槽数量 \(S\)、分位参数 \(\kappa_{\text{dc}}\)/\(\kappa_{\text{prop}}\)、目标网络更新率及重标记策略等协同决定性能，且不同任务的最佳设置存在差异；论文虽提供了消融实验，但未给出自适应调节或自动选择机制。
- 8. **评估指标相对单一**：长时程任务主要报告成功率和平均分，缺少对路径长度、策略鲁棒性、分布外泛化以及训练稳定性等更细粒度的度量，难以全面刻画 DCRL 的行为质量与适用范围。

## 9. 总体评述与展望

DCRL 的核心贡献在于通过递归分治将长时程价值学习的自举深度从线性降低到对数，有效缓解了离线 GCRL 中的误差累积问题。其采用固定中点分解而非最大备份，既保留了精确的价值因子分解结构，又避免了候选选择导致的高估传播；配合并行槽调度，在保持训练多样性的同时实现了从短段到长段的自然课程式学习。

从实验结果看，DCRL 在长时程 OGBench、标准 OGBench 和 CALVIN 等多个基准上均取得领先成绩，尤其作为扁平方法超过了许多分层方法，展示了简洁设计在长程任务上的强大能力。理论与实验相互印证，说明递归分解结构是离线目标条件强化学习中值得深入探索的方向。

不过，方法对确定性动态的依赖、超参数调优复杂度以及计算开销等问题仍限制其更广泛的应用。未来工作可以围绕以下几个方向展开：
- 将精确因子分解扩展到随机 MDP，例如引入条件概率或乘积期望的近似修正；
- 设计自适应槽调度和传播水平选择策略，降低人工调参成本；
- 探索更轻量级的实现方式，减少 CPU 侧递归树生成与槽管理的开销；
- 在更小数据集、多任务迁移以及实时控制等场景下验证方法的鲁棒性。
