## 摘要
组相对强化学习需要等待同一提示的同类展开完成，这对于长且多变的工具使用轨迹而言代价高昂。单流策略优化（SPO）通过持久的提示级价值估计消除了这一依赖，但其配方在优化 token 平均 actor 损失之前会对每条轨迹的一个优势进行白化。我们表明，轨迹中心化通常并不能中心化 actor 所消耗的按 token 加权的量，并通过在动作 token 测度下标准化最终结果优势来修正这一不匹配。此外，我们按生成证据的策略事件而非学习器接收顺序来组织提示证据。在 ALFWorld 的两种模型规模以及 Math-TIR 上的匹配实验中，SPO++ 相比 SPO 提高了在线学习效率。配对消融实验确定，动作 token 测度标准化是所测试组件中作用最强的部分。

## Abstract
Group-relative reinforcement learning waits for sibling rollouts of the same prompt, which is costly for long and variable tool-use trajectories. Single-stream Policy Optimization (SPO) removes this dependency with a persistent prompt-level value estimate, but its recipe whitens one advantage per trajectory before optimizing a token-mean actor loss. We show that trajectory centering generally does not center the token-weighted quantity consumed by the actor, and fix the mismatch by standardizing terminal-outcome advantages under the action-token measure. We additionally organize prompt evidence by the policy event that generated it rather than learner receipt order. Across matched runs on ALFWorld at two model scales and on Math-TIR, SPO++ improves online learning efficiency over SPO. A paired ablation identifies action-token-measure normalization as the strongest tested component.

## 1. 论文的核心问题与整体含义

- **研究背景**：组相对强化学习（如 GRPO）需要等待同一提示下的多个兄弟轨迹全部完成，这对长时程、多工具调用的智能体任务代价很高。
- **SPO 的贡献与遗留问题**：单流策略优化（SPO）用持久的提示级价值估计替代组基线，允许每个提示只采样一条在线轨迹，从而降低异步执行成本；但 SPO 存在两个一致性问题：
  - 轨迹级中心化与 token 平均 actor 损失不匹配；
  - 提示证据的更新顺序依赖学习器接收顺序，而非生成该证据的策略事件顺序。
- **整体含义**：SPO++ 通过“动作 token 测度标准化”和“事件时间提示记忆”两个修正，使单流强化学习的价值基线同时对齐策略时间与 actor 优化所用的测度，从而在保持单次 rollout 依赖的前提下提升在线学习效率。

## 2. 论文提出的方法论

### 2.1 整体思路

SPO++ 保留 SPO 的单 rollout 依赖图和终端结果不变。请求在派发时读取并冻结提示基线；结果返回后，证据按生成该请求的策略事件组织；得到的标量优势在动作 token 测度下标准化，再输入 token 平均 actor 损失。

### 2.2 单流提示价值

- 对可重复任务 \(x\)，SPO 维护成功/失败证据 \((\alpha_x,\beta_x)\)。
- 读取更新前的提示价值：  
  \[
  \hat{v}_x=\frac{\alpha_x}{\alpha_x+\beta_x},\quad A_i=R_i-\hat{v}_x
  \]
- 证据更新引入策略漂移相关的保留因子 \(\rho_i\)：  
  \[
  \alpha_x\leftarrow \rho_i\alpha_x+R_i,\quad
  \beta_x\leftarrow \rho_i\beta_x+(1-R_i)
  \]

### 2.3 事件时间提示记忆

- 定义策略事件坐标 \(z_i\)，对应生成第 \(i\) 条轨迹时发布的 actor 快照。
- 对某个未来派发 \(q\)，设 \(H_q(x)\) 为派发前对任务 \(x\) 可见的历史结果集合，则：
  \[
  \alpha_q=e^{-(z_q-z_0)}\alpha_0+\sum_{i\in H_q(x)} e^{-(z_q-z_i)}R_i
  \]
  \[
  \beta_q=e^{-(z_q-z_0)}\beta_0+\sum_{i\in H_q(x)} e^{-(z_q-z_i)}(1-R_i)
  \]
  其中 \((\alpha_0,\beta_0)\) 为离线初始证据。
- 该构造对固定可见历史和事件坐标下的结果接收顺序具有不变性。
- 实验实现中，保留因子设置 \(\rho=0.875\)，并通过策略事件坐标的几何衰减实现。

### 2.4 动作 token 测度标准化

- 传统轨迹级白化：
  \[
  \mu_{\text{traj}}=\frac{1}{n}\sum_i A_i,\quad
  \sigma_{\text{traj}}^2=\frac{1}{n-1}\sum_i (A_i-\mu_{\text{traj}})^2
  \]
  其均值在轨迹上为零，但 token 平均损失实际看到的是按有效动作 token 数 \(L_i\) 加权的量；当 token 数与优势协方差不等于零时，加权均值不为零。
- SPO++ 改为在动作 token 测度下标准化：
  \[
  \mu_{\text{tok}}=\frac{\sum_i L_i A_i}{\sum_i L_i},\quad
  \sigma_{\text{tok}}^2=\frac{\sum_i L_i (A_i-\mu_{\text{tok}})^2}{\sum_i L_i-1}
  \]
  \[
  \tilde{A}_{\text{tok},i}=\frac{A_i-\mu_{\text{tok}}}{\sigma_{\text{tok}}+10^{-8}}
  \]
- 同一轨迹内所有有效动作 token 拿到相同标量优势，但不同轨迹按 token 测度重新中心化和缩放。

### 2.5 优化与异步执行

- 使用基于不确定性的采样权重，并以策略版本收集最先完成的请求。
- 发布新参数时清空旧策略工作；rollout 重要性比上界截断为 2。
- 对负优势使用 Dual-Clip：SPO 采用 \(c=10\)，SPO++ 采用 \(c=2\)。
- 两个配方均关闭辅助奖励、KL 正则和移动参考更新。
