## 摘要
定位与问题相关的代码区域是自动化软件工程中的关键步骤。然而，由于依赖稀疏的轨迹级信号，现有方法无法识别每一轮动作中哪些是有效的，并且常常在探索过程中发现了正确代码区域却未能将其提交。为解决这些局限，我们提出了一种动作感知的强化学习方法，该方法结合了逐轮奖励序列——既奖励金标准代码区域的发现也奖励其提交——以及动作级优势估计方案，该方案通过对共享相同探索上下文的轮次进行分组来隔离每个动作的贡献。大量评估表明，我们的方法在 SWE-Bench Verified 上平均 F1 较当前最优方法（SOTA）提高了 1.58%，在 SWE-Bench Pro 上提高了 8.55%，且我们的 4B 模型性能优于大至 8 倍的基线模型。代码见 https://github.com/donian00/A2Agent。

## Abstract
Localizing issue-relevant code regions is a critical step in automated software engineering. However, due to their reliance on sparse trajectory-level signals, existing methods cannot identify which per-turn actions are effective and often discover correct code regions during exploration but fail to commit them. To address these limitations, we propose an action-aware reinforcement learning method that combines a per-turn reward sequence rewarding both the discovery and commitment of gold code regions with an action-level advantage estimation scheme that isolates each action's credit by grouping turns sharing the same exploration context. Extensive evaluations show that our method improves the average F1 over the state-of-the-art (SOTA) by 1.58% on SWE-Bench Verified and 8.55% on SWE-Bench Pro, with our 4B model outperforming baselines up to 8x larger. Our code is available at https://github.com/donian00/A2Agent.

# A²Agent 论文总结

## 1. 论文的核心问题与整体含义

- **研究背景**：仓库级代码定位（repository-level code localization）是自动化软件工程中的关键步骤，要求根据 issue 描述在大型代码库中定位需要修改的文件、模块和函数。
- **现有方法的局限**：
  - 依赖稀疏的轨迹级信号，无法区分每一轮动作（tool call）的贡献，导致大量无效、冗余的探索。
  - 即使 agent 在探索过程中观察到了正确的代码区域，也常常无法将其提交到最终预测中（即“发现—提交差距”，Discovery–Commit gap）。
- **论文目标**：提出一种动作感知强化学习方法 **A²Agent**，通过逐轮奖励和动作级优势估计，使 agent 能够学习哪些动作有效、并可靠地提交已发现的金标区域，从而提升定位精度。

## 2. 论文提出的方法论

### 2.1 任务形式化

- 将代码定位建模为多轮决策过程。给定 issue `q` 和固定代码库，agent 在每轮 `t` 选择工具动作 `a_t`，并获得观察 `o_t`，最终在 `T` 轮输出预测 `ŷ = (F, M, U)`，分别对应文件、模块/类、函数/实体三个粒度。
- 动作空间包含 6 个工具：`SearchCodeSnippet`、`TraverseGraph`、`SearchEntity`、`SearchSummary`、`ViewSummary`、`SearchCommit`。

### 2.2 奖励设计

奖励由两部分构成：

- **终端奖励**（第 `T` 轮）：
  - `r_T = r_F1 + r_DC`
  - `r_F1`：三个粒度的 F1 分数之和。
  - `r_DC`（Discovery–Commit 奖励）：衡量探索到的金标位置中被最终提交的比例，公式为
    \[
    r_{DC}=\frac{1}{|I|}\sum_{g\in I} \frac{|E_g \cap Y_g \cap O_g|}{|E_g \cap Y_g|}
    \]
    其中 `E_g`、`Y_g`、`O_g` 分别是粒度 `g` 下探索、金标、预测的位置集合。
- **逐轮奖励**（`t < T`）：
  - `r_t = δ_t^f + δ_t^m + δ_t^u`
  - `δ_t^f/δ_t^m/δ_t^u` 表示该轮新发现的文件/模块/函数金标比例，为部分成功的轨迹提供即时学习信号。

由以上奖励计算折扣回报：
\[
G_t = \sum_{k=t}^{T} \gamma^{k-t} r_k
\]

### 2.3 动作级优势估计

- **状态代理**：由于代码库固定、无自然状态等价，论文定义当前轮前 `K` 个动作的历史序列 `φ_K(t)=⟨a_{t-K},...,a_{t-1}⟩` 作为探索上下文的代理。共享相同 `φ_K(t)` 的轮次被分为一组，组内不同动作可比较。
- **组内标准化优势**：
  \[
  \hat A^{(K)}_t = \frac{G_t - \text{mean}_{j \in G^{(K)}_t} G_t^j}{\sigma_{G^{(K)}_t} + \epsilon}
  \]
  若组内只有一个轮次，则设为 0 以抑制噪声。
- **多深度融合**：结合 `K=1,...,H`（实验中 `H=2`）多个深度的优势，并以轨迹级优势 `A(τ_i)` 作为锚，最终得到：
  \[
  A_t = \omega_0 A(τ_i) + \sum_{K=1}^{H} \omega_K \hat A^{(K)}_t
  \]
  `ω` 为非负权重且和为 1。

### 2.4 两阶段训练流程

1. **教师 SFT 预热**：使用一个强大的教师模型（Qwen3-30B-A3B-Instruct-2507）收集高质量轨迹，筛选出至少在每个粒度命中一个金标位置的轨迹，对预训练 LLM 进行监督微调，得到初始策略 `π_sft`。
2. **动作感知强化学习**：
   - 从当前策略采样 `N=8` 条轨迹/issue。
   - 将 `A_t` 截断到 `[-κ,κ]`，再经 `exp(β·Ã_t)` 转换为 token 权重，并裁剪到 `[w_min,w_max]`。
   - 优化目标为优势加权的最大似然损失：
     \[
     L(θ) = \mathbb{E}_{τ\sim D}\left[ \frac{1}{|V(τ)|} \sum_{i \in V(τ)} w_i \cdot (-\log π_θ(y_i|y_{<i}, τ_{<t_i})) \right]
     \]
   - 迭代执行 rollout 收集与策略更新。

## 6. 论文的主要结论与发现

- **主结果**：
  - SWE-Bench Verified：A²Agent 的平均 F1 比 SOTA（CodeScout-14B）高 1.58%；4B 模型超过 32B 级别的基线。
  - SWE-Bench Pro：平均 F1 比开源 SOTA 高 8.55%；在所有三个粒度上一致优于基线。
- **消融结论**：
  - 仅使用逐轮奖励（无 History Grouping、无 `r_DC`）就已比 GRPO 高 3.54% F1，说明逐轮信号本身价值大。
  - History Grouping 和 `r_DC` 各自独立贡献且互补，联合使用效果最佳。
- **发现—提交差距**：超过 40% 的失败源于发现了金标区域但未提交；`r_DC` 显著缩小该差距并同时提升 F1。
- **历史深度**：`H=2` 最佳；更大的 `H` 导致组内样本过少，优势估计不可靠。
- **推理效率**：A²Agent 的推理时间显著低于其他 agent 基线，平均观察长度减少约 40%。
- **下游任务**：在相同修复流水线下，A²Agent 的 resolve rate 为 38.07%，高于所有基线，接近 Oracle 上限 45.93%。

## 7. 优点

- **细粒度信用分配**：通过动作级优势估计，解决了轨迹级稀疏奖励无法区分动作贡献的问题。
- **针对关键失败模式**：`r_DC` 明确奖励“探索到并提交”金标区域，有效缩小发现—提交差距。
- **计算效率**：小模型（4B/8B）即可超越大模型基线，并且推理时间更短，适合本地部署。
- **与现有工具基础设施兼容**：复用已有工具集和索引方法，改进集中在奖励信号和优化方法上，便于复现和推广。
- **既有理论动机又有实验佐证**：状态代理、多深度融合、锚定项等设计具有明确的动机，并通过消融验证。
