## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验，但在需要高精度、接触密集的装配任务中往往失败，原因是长视程下的信用分配和子任务耦合：当前技能在几何上成功的状态，对下游技能可能是脆弱的。我们展示了在冻结的VLA基础策略上进行残差强化学习时的这种失败模式：恒定的稀疏成功奖励能单独改进每个子任务，但当技能串联时却几乎没有或完全没有增益，因为终端状态的质量没有被控制。我们提出远见残差强化学习，它通过为每个子任务的稀疏成功奖励增加一个离线估计的远见值——即未来子任务成功概率在当前子任务终端状态条件下的概率——来优化交接质量。具体来说，我们（i）从基础策略的终端状态图像中训练一个视觉远见预测器，使用下游 rollout 统计数据进行标注，以及（ii）通过后向远见归纳训练残差策略，将预测器输出作为奖励乘数。在 Isaac Gym 中的一个三阶段基于扳手的螺母拧紧装配任务（抓取、移动插入、旋转）上，我们的方法实现了 85.6% 的完整任务成功率，优于标准的子任务残差强化学习（54.5%）和 VLA 基线，同时保持每个子任务的成功率不变。这些结果凸显出，提升长视程性能需要塑造每个子任务产生哪些成功状态，而不仅仅是成功是否发生。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

### 1. 论文的核心问题与整体含义
- **核心问题**：在长视程、接触丰富的机器人操作任务（如精密装配）中，将整体任务分解为多个子任务并分别训练策略时，存在**子任务间因果耦合**问题。当前子任务在几何上“成功”的终端状态，可能对下游子任务极其脆弱，导致整体任务串联后性能大幅下降。
- **研究动机**：现有的独立子任务强化学习或VLA微调仅用局部稀疏奖励（是否完成当前子任务）优化策略，会**忽略终端状态的质量**，即未能区分哪些成功状态更利于后续任务。即便子任务成功率很高，串联后的全任务成功率也可能没有提升甚至恶化。
- **整体含义**：提出“远见残差强化学习”，核心思想不是只追求子任务“是否成功”，而是用**未来成功概率**引导策略，主动塑造终端状态以**优化交接质量**，从而实现真正有效的长视程技能组合。

### 2. 方法论
- **核心思想**：为每个子任务的局部稀疏奖励引入一个**远见价值**（foresight value）作为乘数，该价值定义为当前子任务终端状态下，未来所有子任务成功的概率。这样训练出的策略会主动选择更有利于下游任务的终端状态。
- **关键技术细节**：
  - **残差策略框架**：在冻结的VLA基础策略（π0）上附加一个小的残差策略（输出按比例α混合），仅利用腕部相机图像和DINOv2特征，通过PPO训练进行行为校正。
  - **视觉远见预测器**：离线训练一个神经网络预测器 `pϕ`，输入为当前子任务终端状态的图像，输出为下一个子任务成功的概率。训练数据通过：a) 大量运行基础策略收集成功终端状态；b) 对每个终端状态多次运行已训练好的下游策略，统计成功次数；c) 用二项负对数似然损失进行拟合。该预测器仅用于训练，不在评估时使用。
  - **后向远见归纳训练**：从最后一个子任务开始反向训练。最后一个阶段用普通奖励训练；对于前面的子任务，其奖励为 `r_t = βk(s_{t+1}) * pϕ(o_{t+1})`，其中βk是局部成功指示，`pϕ`是已训练好的远见预测器，充当Vk+1:K的估计。这样确保训练阶段k时，其下游策略πk+1:K已完成并固定，保证了奖励的平稳性。
- **理论对应**：该方法可视为MAXQ分层强化学习中完成函数（completion function）的一个在线解耦、可扩展的实现。

### 3. 实验设计
- **任务场景**：在NVIDIA Isaac Gym仿真环境中执行**三阶段扳手螺母拧紧装配任务**：抓取（160步）→ 移动插入（200步）→ 旋转（200步）。任务对精度要求极高（扳手与螺母间隙小于2mm），且须在旋转时主动保持插入。
- **观察与动作**：输入为2个256×256 RGB图像（第三人称和腕部）及8维本体感知；输出为7维末端位姿增量（3维位置+3维轴角旋转+1维抓手指令），控制频率20Hz。物体初始位姿随机化。
- **基准对比方法**：
  - **π0（端到端）**：直接训练π0完成整个任务。
  - **π0（串联）**：三个子任务独立训练后串联执行。
  - **π0 + 残差RL**：在基础π0上加残差策略，但使用恒定稀疏成功奖励（无远见修正）。
  - **π0 + 残差RL + 远见（本文方法）**。
- **训练数据**：每个子任务用包含特权信息的专家策略收集2560条演示，用于微调π0基础策略。

### 7. 优点
- **问题洞察深刻**：精准指出长视程操作中“子任务成功≠可组合”的核心矛盾，并给出了量化证据。
- **方法论简洁有效**：通过离线预测器 + 反向归纳将远见价值与残差RL解耦，避免了在线分层训练的复杂性和非平稳性，易于与预训练VLA模型结合。
- **理论联系明确**：与MAXQ价值分解理论挂钩，但提供了更实用的近似和部署方案。
- **实验设计具有说服力**：通过oracle vs. 串联、奖励分数分析等手段，清晰验证了机制假说——不是提升子任务成功率，而是优化成功状态的分布。

### 8. 不足与局限
- **仿真到真机迁移未验证**：全部实验在仿真中完成，作者也指出硬件上RL成本是潜在障碍，但尚未演示sim2real能力。
- **任务和模型单一**：仅在一个特定的拧紧装配任务和π0模型上评估，泛化性存疑。
- **阶段分解需预定义**：要求任务可被明确分解为线性阶段，且成功谓词已知，限制了在无结构长任务上的应用。
- **远景预测的近视近似**：使用了单步远景近似（只考虑下一阶段成功概率），虽然可扩展至多步，但当前未演示深层耦合效果。
- **数据收集成本**：训练每个预测器需要2560个终端状态，每个需对固定下游策略执行5次完整的后继rollout，在复杂任务中可能较昂贵。
- **残差策略输入简化**：残差策略仅用腕部相机，可能丢失全局场景信息，虽有助于专注校正，但也限制了校正能力。
