## 摘要
无人机巡检的自主导航问题仍然具有挑战性，因为这需要它在靠近障碍物的地方有效导航，同时还要考虑动态风险因素，如天气条件、通信可靠性和电池续航能力。本文介绍了MOAR路径规划器，它解决了任务过程中风险演变带来的复杂性。它提供实时轨迹适应能力，同时优化安全性、时间和能耗。该规划器采用风险感知代价函数，该函数集成了预计算代价地图、损伤代价和插入代价的新概念，以及自适应速度规划框架。在此基础上，利用状态和动作空间的离散表示在图结构中搜索最优路径。通过仿真和实际飞行测试对该方法进行了评估。结果表明，它能够生成覆盖广泛评价指标的实时轨迹：约占流行算法所覆盖范围的90%。所提出的框架有助于无人机在关键任务中实现更自主和可靠的导航。

## Abstract
The problem of autonomous navigation for UAV inspection remains challenging as it requires effectively navigating in close proximity to obstacles, while accounting for dynamic risk factors such as weather conditions, communication reliability, and battery autonomy. This paper introduces the MOAR path planner which addresses the complexities of evolving risks during missions. It offers real-time trajectory adaptation while concurrently optimizing safety, time, and energy. The planner employs a risk-aware cost function that integrates pre-computed cost maps, the new concepts of damage and insertion costs, and an adaptive speed planning framework. With that, the optimal path is searched in a graph using a discrete representation of the state and action spaces. The method is evaluated through simulations and real-world flight tests. The results show the capability to generate real-time trajectories spanning a broad range of evaluation metrics: around 90% of the range occupied by popular algorithms. The proposed framework contributes by enabling UAVs to navigate more autonomously and reliably in critical missions.

### 2. 方法论
- **多目标代价函数**：  
  总代价 \(J = k_S SC + k_T TC + k_E EC\)，其中 \(SC\) 为安全代价，\(TC\) 为时间代价，\(EC\) 为能耗代价，\(k_S, k_T, k_E\) 为权重系数。
  - **安全代价** \(SC_i\)：由三项组成，即碰撞代价（与障碍物距离）、插入代价（相对于凸包的位置）和损伤代价（防止坠落后造成严重损坏的水平距离）。每项通过势场函数 \(C(d)\) 在最小距离 \(d_{min}\) 和最大距离 \(d_{max}\) 间线性插值得到，并归一化至 \([0,1]\)。
  - **时间代价** \(TC_i\)：路径段长度除以自适应速度 \(v(d_{obs}, \theta)\)，速度依赖于飞行方向 \(\theta\) 和距障碍物距离 \(d_{obs}\)。速度饱和函数 \(v_{sat}(d_{obs})\) 在安全区域为最大巡航速度 \(v_{MAX}\)，贴近障碍物时为最小速度 \(v_{MIN}\)，中间区域线性过渡。
  - **能耗代价** \(EC_i\)：相邻节点速度变化量的平方除以最大允许速度变化 \(v_{MAX}\)，用于惩罚过大的加减速。
- **图搜索**：  
  将 2D 平面（竖直剖面）及飞行方向离散化为 3D 图，每个节点连接 9 个邻域节点（8 个方向+悬停），使用 A*（到达指定目标点）或 Dijkstra（到达出口或紧急降落区域）搜索最优路径。启发函数为到达目标点的最短时间界加上制动能耗代价。
- **风险感知系数调整**：  
  定义四个风险指标：风风险 \(WR\)、通信风险 \(CR\)、定位风险 \(LR\)、电池风险 \(BR\)，均归一化到 \([0,1]\)。通过线性映射将风险值转换为代价函数权重的实时偏移，使高风险时偏向安全，低电量时偏向快速和节能。例如：  
  \(k_S = \gamma k_{S,0} (1 + \frac{1}{2}WR + \frac{1}{4}CR + \frac{1}{4}LR - BR)\)  
  \(k_T = \gamma k_{T,0} (1 - (\frac{1}{2}WR + \frac{1}{4}CR + \frac{1}{4}LR - BR))\)  
  \(k_E = \gamma k_{E,0} (1 + \frac{1}{2}WR + \frac{1}{2}BR)\)  
  并强制 \(k_S + k_T + k_E = 1\)。

### 3. 实验设计
- **仿真环境**：

- **对比方法（基准）**：  
  - A*/Dijkstra（最短路径，最快）  
  - Voronoi 图搜索（等距于障碍物，安全与速度折中）  
  - 包络线搜索（沿最外围边界移动，最安全）  
  这三种朴素算法分别代表速度优先、平衡和安全优先的策略。
- **评价指标**：  
  路径长度、路径时间、与最近障碍物的平均距离、总速度变化量。
- **实验设置**：  
  在不同环境、不同起始位置下测试巡检、退出（Exit）和紧急降落（Evacuation）三种任务类型。做了 36 组仿真试验，文中展示 3 个代表性案例。另外对权重系数进行了 0 ~ 1 步长 0.05 的灵敏度扫描，并改变风、电池、GPS 等风险因子以验证自适应行为。最后用 LineDrone 物理样机在输电线模型上进行了真实飞行测试。

### 6. 主要结论与发现
- MOAR 规划器能够生成覆盖基准算法评价指标约 90% 范围的轨迹，通过实时调整代价函数权重，可在最短路径与最安全路径之间平滑过渡。
- 安全代价中的插入代价和损伤代价使路径在贴近障碍物时能更智能地选择外部绕行或防止坠落后严重损坏的位置。
- 自适应速度规划使无人机在空旷区域快速飞行，在贴近障碍物时减速，实现时间与安全之间的进一步折中。
- 物理实验证实该算法可在机载嵌入式设备上实时运行，产生的真实飞行轨迹与规划结果基本一致。

### 7. 优点
- **实时性与轻量级**：预计算代价图加离散图搜索，计算量极低，适合嵌入式平台。
- **多模态风险适应**：将天气、通信、定位、电池等抽象为风险指标，动态调节权重，属于一种实用的决策框架。
- **创新的代价项**：引入损伤代价和插入代价，使路径不仅考虑碰撞，还顾及坠落的后果和是否安全地嵌入结构内部。
- **灵活的速度规划**：飞行速度随障碍物距离变化，且考虑方向性的最大巡航速度，贴近真实飞行特性。

### 8. 不足与局限
- **问题简化**：将 3D 巡检简化为 2D 竖直平面，且假设无人机低速飞行、无显著滚转角，忽略动力学约束，可能不适用于高速或高机动场景。
- **能耗模型简化**：仅用速度变化量衡量能耗，未考虑空气阻力、风速、质量等实际因素，对续航的优化可能不够精确。
- **对比实验薄弱**：仅与 A*、Voronoi、包络线这些朴素方法对比，未与现有多目标路径规划算法（如 NA‑MOA*、加权聚合的 A* 等）进行定量比较，难以体现相对优势。
- **真实测试有限**：仅一次物理实验，且速度较低、任务简单，不足以验证在复杂环境和动态风险中的全程自适应能力。
- **风险映射依赖经验**：权重系数与风险指标的线性映射规则和初始系数 \(k_{*,0}\) 均为经验设定，缺乏系统调优或学习机制，迁移到新平台或任务时可能需要重新设计。
- **离散分辨率限制**：图分辨率固定为 0.3 m，在精细作业或极近距离避障时可能产生次优路径。
