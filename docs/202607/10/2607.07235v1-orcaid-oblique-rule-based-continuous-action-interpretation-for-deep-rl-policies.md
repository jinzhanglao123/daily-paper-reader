## 摘要
可解释性仍是强化学习的一个关键问题。在动作空间连续的情况下，从复杂环境中训练的智能体中提炼可解释的策略尤其具有挑战性。我们提出ORCAID，一种从具有连续动作空间的混合连续-离散环境中运行的强化学习智能体提取可解释的基于规则的策略的新方法。我们的主要贡献是一种高效倾斜决策树训练算法，该算法通过超平面对状态空间进行划分并拟合局部线性模型。其核心思想在于三阶段分裂搜索：高效的随机初始化、局部求精和反向消除。最后，合并相邻叶节点以产生一组描述给定深度强化学习策略的简洁可解释规则。我们在多个强化学习环境中评估ORCAID，证明提取的基于规则的策略以较少的参数量保持强大性能，甚至可用于改善原始深度强化学习策略的性能。

## Abstract
Explainability remains a key issue in reinforcement learning (RL). Distilling an interpretable policy from an agent trained in a complex environment is particularly challenging when the action space is continuous. We introduce ORCAID, a novel method for extracting interpretable rule-based policies from RL agents operating in mixed continuous-discrete environments with continuous action spaces. Our main contribution is an efficient oblique decision tree training algorithm that partitions the state space by hyperplanes and fits local linear models. The key idea lies in a three-stage split search: efficient random initialization, local refinement, and backward elimination. Finally, adjacent leaves are merged to yield a concise set of interpretable rules describing a given deep RL policy. We evaluate ORCAID across multiple RL environments, demonstrating that the extracted rule-based policies maintain strong performance with a low number of parameters and can even be used to improve the performance of the original deep RL policy.

### **2. 论文提出的方法论**

ORCAID的核心思想是通过倾斜决策树对状态空间进行超平面划分，并在每个划分区域内用线性模型来近似动作，最后将其简化为规则集。整个过程包含三个主要阶段：

*   **数据收集与增强**：
    *   **执行与标注**：执行原始RL策略收集状态-动作轨迹数据。
    *   **聚类与重采样**：为解决轨迹数据分布不均的问题，对状态进行K-means聚类，并围绕聚类中心添加高斯噪声进行重采样，以增强数据覆盖并防止过拟合。
*   **树构建与超平面优化**：
    *   **递归划分**：构建倾斜决策树（Oblique Decision Tree），每个内部节点代表一个基于超平面的分裂条件（`w·x ≤ b`），而非传统的轴对齐分裂。
    *   **三阶段分裂搜索**（核心算法）：
        1.  **降维与缩放**：应用PCA降维和Min-Max缩放，提高计算稳定性。
        2.  **随机初始化**：在PCA空间中随机采样多个超平面，快速筛选出有潜力的候选者。
        3.  **局部优化**：对最佳候选者使用差分进化算法进一步优化，以最小化分裂后的加权均方误差。
    *   **叶节点建模**：在每个叶节点（即一个状态子区域），为每个动作维度拟合一个独立的线性回归模型，并通过**反向特征消除**简化模型。

*   **简化与规则合并**：
    *   **区域合并**：识别并合并那些相邻且线性模型相似的叶节点区域，以减少规则总数。
    *   **逻辑简化**：合并后的区域定义可能是合取项的析取式（DNF），使用Quine-McCluskey方法对其进行逻辑简化。
    *   **规则生成**：最终产出形式为`IF (超平面条件逻辑组合) THEN (输出为特征的线性方程)`的可解释规则集。
*   **迭代优化（DAgger循环）**：
    *   为修正替代模型与原始策略间的累积误差（模型漂移），采用DAgger（数据集聚合）框架进行迭代改进：用当前规则模型在环境中运行，收集其与原始策略决策偏差较大的状态，重新标注并加入训练集重新训练。

*   **实验组数**：
    *   **主体实验**：在9个不同环境中，对4种方法（ORCAID及3种基线）进行性能对比，共**36组实验**。每组实验用3个不同的RL策略种子和3个不同的替代模型种子进行重复，共9次运行，确保了结果的统计稳定性。
    *   **策略改进实验**：对7个环境（排除了两个已最优策略）进行了策略改进测试，并设置了**4种不同的规则镜像策略**和每个策略**50次随机变换**。
    *   **消融研究（Ablation Study）**：对Pendulum和Swimmer两个环境，系统性地调整了6个关键超参数（如步数、噪声、聚类数等），并测试了移除线性回归、DAgger和区域简化等核心组件的效果。
    *   **可解释性评估**：引入LLM-as-a-Judge框架，使用6种不同的LLM，针对15个可解释性问题对模型进行评估。
*   **充分性与公平性**：实验设计非常全面和严谨。它覆盖了从简单到复杂的多种任务类型，对比了当时最先进的基于规则的解释方法，并通过统一次参数、训练框架和模型大小度量，确保了对比的公平性。消融实验清晰地验证了各部分设计的有效性。

### **6. 论文的主要结论与发现**

*   **高保真度与高性能（RQ1 & RQ2）**：ORCAID提取的规则策略在保证与原始RL策略**性能比（Reward Ratio）更高或相当**的同时，其**模型复杂度（Model Size）远小于**决策树（DT）和RuleFit，也优于其最接近的竞争者Cubist。同时，它在测试集上的**均方误差（MSE）最低**，表明其保真度最高。
*   **策略可改进性（RQ3）**：通过镜像规则并在特定区域强制执行，ORCAID生成的规则能有效发现并改进原始RL策略的弱点（即获得更高奖励），其发现弱点的频率和最大改进幅度均高于其他基线方法。
*   **更好的可解释性（RQ4）**：LLM-as-a-Judge的定量评估显示，ORCAID模型在可解释性维度上的得分普遍高于决策树和Cubist，尤其是在模型性能相当或更优的情况下。LLM的定性反馈指出，ORCAID能用更少的、物理意义更明确的模式来划分状态空间，而决策树或Cubist的划分则更显琐碎和缺乏全局逻辑。

### **7. 优点**

*   **方法论创新**：首次提出用倾斜决策树处理**混合状态空间与连续动作空间**的策略解释问题，并设计了三阶段高效超平面搜索算法。
*   **模型简洁性**：通过简化与合并，生成非常简洁的“IF-THEN”规则，极大地降低了模型复杂度，提升了可解释性。
*   **实验设计严谨**：
    *   **对比公平性**：统一了所有方法的DAgger训练框架和超参数搜寻方式。
    *   **评估综合性**：从性能、保真度、可解释性、可行动性（策略改进）四个维度进行全方位评估。
    *   **评估创新性**：采用LLM-as-a-Judge方法对可解释性进行量化分析，弥补了传统模型复杂度指标的不足。
*   **工具化与应用潜力**：提供了交互式可视化工具，并能直接用于发现和改进原始RL策略的弱点，具有很高的实用价值。

### **8. 不足与局限**

*   **实验规模上限**：当前评估的Hopper和Half Cheetah任务状态维度最高达17维，动作维度最高6维。方法在更高维、更复杂环境中的可扩展性有待考证，可能需要额外的降维或特征选择技术。
*   **策略类型局限**：方法设计主要针对**确定性策略**，虽然文中提出向线性高斯模型扩展以支持随机策略的思路，但目前尚未实现。
*   **数据依赖与模型漂移风险**：方法依赖与环境的交互来收集数据（DAgger），如果无法与环境进行交互查询，则无法应用DAgger来提升保真度和性能。
*   **可解释性评估的局限性**：尽管使用了LLM法官，但LLM的评判与人类专家评判的一致性仍需进一步验证。
*   **训练效率**：在复杂任务（如Half Cheetah）上，ORCAID的训练时间（30分钟）显著长于决策树（15秒），虽然换来性能和解译性的大幅提升，但其训练效率仍有优化空间。
