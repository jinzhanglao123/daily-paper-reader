## 摘要
本文介绍了一种将时间行为树（TBT）解释为用于强化学习（RL）的奖励Petri网（RPN）的方法。为复杂的长期机器人任务设计奖励函数非常困难，尤其是当任务具有层次结构和时间约束时。TBT 通过将时间属性融入其叶节点，扩展了机器人应用中使用的传统行为树（BT）。这使得 TBT 不仅能表示由 BT 操作符（如 Sequence、Fallback 和 Parallel）定义的行为任务结构，还能表示任务的时间约束。在本工作中，叶节点中的约束使用线性时序逻辑指定。为了利用 TBT 为 RL 提供奖励信息，我们提供了从 TBT 到 Petri 网（PN）的转换，并展示了如何根据 TBT 的结构自动分配奖励，从而得到 RPN。在一系列难度递增的环境中，我们展示了基于 TBT 的奖励如何在普通 RL 失败的情况下实现学习，提高样本效率，并为学习过程提供灵活、直观的控制。我们通过使用不同的奖励分配方案和 TBT 结构来展示对学习的影响。

## Abstract
This paper introduces an interpretation of Temporal Behavior Trees (TBTs) as Reward-Petri-Nets (RPNs) for reinforcement learning (RL). Designing reward functions for complex, long-horizon robotic tasks is notoriously difficult, especially when tasks have hierarchical structure and temporal constraints. TBTs extend conventional behavior trees (BTs) used in robotic applications by incorporating temporal properties into their leaf nodes. This allows TBTs to represents not only the behavioral task structure defined by BT operators such as Sequence, Fallback, and Parallel, but also the task's temporal constraints. In this work, the constraints are specified in the leaf nodes using Linear Temporal Logic. In order to inform RL rewards using TBTs, we provide a translation from TBT into a Petri Net (PN) and show how rewards can be automatically assigned based on the TBT's structure, resulting in a RPN. In a series of increasingly challenging environments, we demonstrate how TBT-based rewards enable learning where vanilla RL fails, improve sample efficiency, and offer flexible, intuitive control over the learning progress. We showcase the learning impact by using different reward distribution schemes and TBT structures.

## 2. 方法论
- **核心思想**：利用 TBT 既描述行为结构（顺序、回退、并行）又描述叶节点的时序逻辑约束的特性，将其递归转换为 Petri 网，并通过添加守卫、动作和奖励函数将其扩展为 RPN，然后嵌入马尔可夫决策过程（MDP）用于 RL 训练。
- **关键技术细节**：
  - **TBT 到 Petri 网的翻译**：
    - 叶节点 `Leaf(φ)` 转换为包含 `p?φ`、`tφ`、`pφ` 和 `t¬φ` 的结构，其中 `tφ` 表示满足公式 φ，`t¬φ` 表示违反。
    - 控制流节点（`Sequence`、`Fallback`、`Parallel`）通过连接对应的子网来建模，使用同步位置与控制令牌来保证语义正确。
  - **守卫与动作**：
    - 为每个叶节点构造 LTL₃ 监视自动机，将自动机的判决（`true`、`false`、`?`）作为变迁 `tφ` 和 `t¬φ` 的守卫，消除非确定性。
    - 变迁可触发自动机的启动/停止动作，支持“回溯”（backtracking）：当自动机判 `false` 时，允许重置该子任务以重新尝试。
  - **奖励分配**：
    - 定义 `RPN` 中的奖励函数 `R: T → ℝ`。
    - 提供分配函数集合 `(fnLeaf, fnFback, fnParrM, fnSeq)`，按 TBT 的递归结构将全局奖励逐步分发至叶节点的成功/失败变迁。
    - 支持多种分配策略，例如统一分配（均匀分给所有节点）和单调递增（越靠后的子目标奖励越大），并引入失败惩罚（如 `R(t¬φ) = -α·R(tφ)`）。
  - **嵌入 MDP**：将 MDP 状态与 RPN 标记组合为扩展状态，每一步根据自动机判决更新 RPN，并将所有使能变迁的奖励之和作为该步的 RL 奖励。

- **对比方法**：

  - **TBT-Uniform**：所有节点均匀分配奖励。
  - **TBT-Mon Inc**：奖励沿 RPN 单调递增地分配给叶节点，以激励完成后续子目标。

## 6. 主要结论与发现
- TBT 驱动的奖励使 RL 在 **Vanilla RL 完全失败**的困难探索任务中成功学会策略。
- **TBT-Baseline**（稀疏 RPN）已经能够提高样本效率，但方差大且不如密集奖励。
- **TBT-Mon Inc**（单调递增分配）在更复杂的迷宫环境中展现出略微更快的收敛速度和稳定性。
- TBT 方法能够随环境复杂度扩展，有效解决长时域探索问题，训练到稳定策略所需的 episode 数控制在大约 3×10³ 到 13×10³ 之间（除最简单的 Unlock 外）。

## 7. 优点
- **结构与逻辑结合**：将行为树的层次结构与线性时序逻辑集成，统一表达任务行为和时序约束。
- **自动奖励生成**：通过 RPN 自动将任务结构映射为奖励，减轻人工设计奖励的负担。
- **模块化与可读性**：TBT 便于人类理解和修改，支持参数化快捷方式，易于在不同场景间迁移和复用。
- **灵活的控制**：通过不同的分配函数和 TBT 结构，用户可以直观地调整各子任务的相对重要性和奖励分布。
- **避免状态爆炸**：基于 Petri 网的表示对并行结构友好，有利于处理复杂组合任务。

## 8. 不足与局限
- **理论局限**：当 TBT 叶节点自动机可能产生 `false` 时，`M(pT)=1` 未必意味着轨迹满足规范（定理 1）；只在无 `false` 输出时成立（定理 2），实际中可能存在模糊性。

- **计算开销**：LTL 自动机及 Petri 网的同步更新可能带来额外计算开销，论文未详细分析其在大状态空间中的效率。
