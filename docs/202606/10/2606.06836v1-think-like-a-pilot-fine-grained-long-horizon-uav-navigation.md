## 摘要
语言引导的无人机智能体需要执行长时域语义指令，同时生成平滑且物理可行的连续飞行命令，然而现有的视觉语言导航（VLN）基准通常采用离散或粗略的动作，而现有的无人机视觉语言动作（VLA）任务则侧重于短期的原子操作。为解决无人机任务设定中的这一差距，我们引入了FLIGHT，一个面向混合无人机导航与推理任务的细粒度长时域指令引导基准，该基准结合了多阶段指令与密集的六自由度轨迹标注，包含两个数据集划分：细粒度VLN和长时域流。为使无人机智能体具备在飞行过程中对任务执行状态和任务规划进行实时推理的能力，同时满足高频实时精准控制的需求，我们进一步提出了FLIGHT VLA，一种异步架构，将用于任务状态推理的低频流式飞行员视觉语言模型（VLM）与用于连续控制的高频扩散动作模型解耦，并通过显式的飞行员推理文本进行监督，这些文本总结了当前飞行状态并预测下一子目标。在闭环评估中，FLIGHT VLA在我们的FLIGHT基准上始终优于代表性的VLN和VLA基线，实现了更强的多阶段完成度、子目标遵循度以及终端控制。其训练后的流式飞行员推理VLM进一步提升了无人机视频推理能力，验证了我们设计的有效性。

## Abstract
Language-guided UAV agents must execute long-horizon semantic instructions while producing smooth, physically feasible continuous flight commands, yet existing Vision-Language Navigation (VLN) benchmarks typically use discrete or coarse actions and existing UAV Vision-Language-Action (VLA) tasks focus on short, atomic maneuvers. To address this gap in UAV task settings, we introduce \textbf{FLIGHT}, a \textbf{F}ine-grained \textbf{L}ong-horizon \textbf{I}nstruction-\textbf{G}uided benchmark for \textbf{H}ybrid UAV navigation and reasoning \textbf{T}asks, which combines multi-stage instructions with dense 6-DoF trajectory annotations across two dataset splits: Fine-grained VLN and Long-horizon Flow. To endow the UAV agent with the capability of real-time in-flight reasoning over task execution status and mission planning, while simultaneously accommodating high-frequency, real-time precise control, we further propose \textbf{FLIGHT VLA}, an asynchronous architecture that decouples a low-frequency Streaming Pilot Vision-Language Model (VLM) for task-state reasoning from a high-frequency diffusion action model for continuous control, supervised by explicit \textbf{Pilot Reasoning} texts that summarize the current flight state and anticipate the next subgoal. In closed-loop evaluation, FLIGHT VLA consistently surpasses representative VLN and VLA baselines on our FLIGHT benchmarks, achieving stronger multi-stage completion, subgoal adherence, and terminal control. Its trained Streaming Pilot Reasoning VLM further improves UAV video reasoning, validating the effectiveness of our design.

*   **整体含义**：论文试图填补这一空白，提出一个既能评估“像飞行员一样”长期规划与推理，又能衡量细粒度连续飞行控制的基准与框架，推动语言引导的无人机从简单的目的地寻找或短期操控，走向复杂的、多阶段组合的自主飞行任务。

## 2. 论文提出的方法论
### 2.1 核心思想：异步快－慢推理与控制架构
面对长时域任务中“语义推理需重型模型（低频）、飞行控制需实时高频”的时间尺度冲突，论文提出 **FLIGHT VLA** 架构，将系统解耦为两个并行模块：
*   **慢速推理模块（Streaming Pilot VLM）**：以低频率（≈0.5~1Hz）运行，处理视觉流、指令和历史记忆，输出当前飞行状态分析与下一子目标预测（即“飞行员推理”文本）以及对应的语义隐层特征。
*   **快速执行模块（Diffusion Action Model）**：以高频率（≈10~30Hz）运行，接收实时视觉、位姿状态以及慢速模块最新可用的语义特征，生成未来一段时间的连续六自由度动作序列，从而填补推理间隙，保证飞行平稳。

### 2.2 关键技术细节
*   **FLIGHT 基准任务定义**：
    *   **细粒度 VLN (Fine-Grained VLN)**：在传统 VLN 基础上，指令包含密集的地标约束和局部子任务，动作空间由离散选择变为连续相对位移与姿态的序列，要求无人机严格按子目标顺序完成导航并精准着陆。
    *   **长时域流 (Long-Horizon Flow)**：将 UAV-Flow 的原子动作（如穿越、绕飞、起降）组合成多阶段长序列指令，模型需理解“先…后…最后…”并贯彻到连续飞行中。
    *   **飞行员推理任务**：给定无人机 FPV 视频和指令，用 VLM 生成当前状态与下一步计划的文本，用于评估模型的规划能力。
*   **飞行员推理（Pilot Reasoning）机制**：从人类专家演示中，利用 VLM 辅助生成每个关键节点的推理文本（“State: [当前状态] Next: [下一动作]”），显式地将飞行员的决策思维链标注出来，作为训练信号和认知锚点。
*   **FLIGHT VLA 形式化与流程**：
    *   慢速推理模块：在时刻  $\tau$ ，VLM  $g_\phi$  输入指令、视觉窗口、状态窗口和历史推理记忆窗口，输出推理文本  $M_\tau$  和语义特征  $z_\tau$ （取输入隐藏状态与输出推理文本隐藏状态的聚合）。
    *   快速动作模块：在控制步  $t$ ，Action Model  $f_\theta$  用独立视觉编码器提取当前帧特征  $\mathbf{f}_t$ ，并以 VLM 推理时刻为参考系编码相对姿态  $\mathbf{q}_t$ ，结合最新的语义特征  $z_{\tau(t)}$ （可能来自过去时刻），通过扩散 Transformer（DiT-B）生成动作序列  $A_t$ 。
    *   训练采用 **两阶段策略**：先联合训练 VLM 和 DiT，再冻结 VLM 微调 DiT。
    *   **延迟感知对齐**：显式模拟 VLM 推理延迟，在构造训练数据时，对不同动作块随机采样不同历史时间偏移的语义特征（如1秒、3秒延迟），使动作模型学会利用当前视觉和相对姿态补偿语义信息的滞后，实现稳定的异步部署。

### 2.3 数据集构建流水线
*   **数据采集**：在 Unrealzoo 仿真环境中由人类飞行员飞行，记录 6-DoF 轨迹和 FPV 视频，少量简单路线由规划模型补充。
*   **标注**：分三步——① 规则驱动从遥测数据提取关键动作时间并生成元数据；② 将视频分段，结合元数据提示送入 VLM，为每一段生成动作+环境描述；③ 用 LLM 将分段描述融合为全局指令；④ 将分段视频与当前段、下一段任务描述一起送入 VLM，生成“飞行员推理”文本（当前状态分析+下一步计划），并人工复核。

## 6. 论文的主要结论与发现
*   **FLIGHT VLA 在长时域无人机控制上显著超越现有基线**：在长时域 Flow 任务上，SR 达到 59%，远超 OpenVLA（10.5%）和 Memory VLA（18.5%），且能完成多达 7 个子任务的指令。在细粒度 VLN 上，SR 与 NaVid 相近（13.5% vs 13.0%），但 OSR 与 NE 更优，且关键的指令遵循率 IASR 高出 6 个百分点（11% vs 5%），表明模型对多阶段子任务的执行更为忠贯。

## 7. 优点
*   **基准填补空白且设计细腻**：FLIGHT 基准首次将长时域指令与细粒度六自由度连续控制纳入统一任务，指令标注含密集地标与子目标，指标 IASR 直接衡量指令顺序执行忠实度，比传统 VLN 的终点成功更有意义。
*   **“飞行员推理”概念新颖实用**：将飞行员决策链显式化为“状态+下一步”的短文本，既充当了认知锚点，又压缩了历史信息，连接高层语义与低层动作，且标注方式自动高效。
*   **架构设计创新且实用**：异步快－慢双模块天然匹配具身智能体的现实要求，动作预测采用连续序列+相对位姿，充分考虑 VLM 延迟并进行了延迟感知训练，提高了实际可部署性。
*   **实验对比全面且效果显著**：涵盖了主要相关基线，在多个指标上取得一致提升，尤其子任务完成率提升突出。

## 8. 不足与局限
*   **仅限仿真验证，缺少现实世界迁移**：所有数据、训练和评估均在模拟器中完成，未讨论域差异，不保证在真实无人机上的稳定性与安全性，sim-to-real 方面的挑战未触及。
*   **部分实验结果绝对值仍较低，任务难度大**：细粒度 VLN 任务上 SR 仅 13.5%，IASR 仅 11%，说明对于长距离、多复杂子任务的导航，方法仍有极大提升空间。
*   **未进行消融实验与误差分析**：没有通过拆解组件来量化“飞行员推理文本监督”“延迟感知训练模块”“双模块异步架构”各自的贡献，无法揭示哪个部分是性能提升的关键。也没有分析失败案例的模式（如语义漂移、子目标遗忘）。

*   **推理过程依赖黑盒 VLM**：飞行员推理的生成质量和可靠性仍然取决于 VLM 本身的推理能力，可能存在幻觉或错误的规划，而论文未探讨此类风险的缓解措施。
