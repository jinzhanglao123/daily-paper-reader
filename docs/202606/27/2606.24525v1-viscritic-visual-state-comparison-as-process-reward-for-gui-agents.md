## 摘要
基于视觉语言模型的GUI智能体在自动化数字任务方面展现出巨大潜力，但在长时域场景中常因缺乏步骤级验证而失败。现有的过程奖励模型仅通过文本推理来验证动作，忽略了GUI状态变化的视觉本质。我们提出了VisCritic，一个视觉过程奖励框架，通过在视觉特征空间中直接比较动作前后的截图来验证智能体的动作。VisCritic采用孪生视觉变换器提取变化感知表征，并结合动作感知评判头，联合评估动作成功、任务进展和错误类型。我们设计了一条评判训练数据构建流程，从现有轨迹中生成弱监督样本，无需额外人工标注即可训练评判模型。在五个基准测试上的实验和离线分析表明，VisCritic可作为即插即用的增强模块，适用于多种GUI智能体，普遍提升基准指标，同时提供视觉诊断线索。

## Abstract
GUI agents powered by vision-language models show strong potential for automating digital tasks, yet frequently fail in long-horizon scenarios due to the absence of step-level verification. Existing process reward models verify actions through textual reasoning alone, missing the visual nature of GUI state changes. We introduce VisCritic, a visual process reward framework that verifies agent actions by directly comparing pre-action and post-action screenshots in visual feature space. VisCritic employs a Siamese vision transformer to extract change-aware representations, coupled with an Action-Aware Critic Head that jointly evaluates action success, task progress, and error type. A critic-training data construction pipeline generates weakly supervised samples from existing trajectories without additional human labels for critic training. Experiments and offline analyses across five benchmarks demonstrate that VisCritic serves as a plug-and-play enhancement for diverse GUI agents, generally improving benchmark metrics while providing visual diagnostic cues.

### 2. 论文提出的方法论
论文提出了**VisCritic**，一个视觉过程奖励框架，其核心思想是直接比较动作前后的截图，以验证动作是否成功。框架由三个关键部分构成：
- **视觉差异编码器**:
    - 采用**孪生视觉变换器**架构，使用共享权重的ViT分别提取动作前(`s_t`)和动作后(`s_{t+1}`)截图的补丁级特征(`F_t`, `F_{t+1}`)。
    - 计算补丁级差异特征 `ΔF = F_{t+1} - F_t`，并基于此生成一个**变化幅度图** `M`，以标识语义变化显著的区域。
    - 引入**变化区域注意力**机制，通过一个可学习的温度参数 `β` 将变化幅度图 `M` 转换为注意力权重 `α`，并利用其对差异特征进行加权池化，得到聚焦的差异表征向量 `v_Δ`。这使得模型能专注于有意义的UI变化，忽略渲染噪声。
- **动作感知评判头**:
    - 将提取的视觉差异表征 `v_Δ` 与动作文本 `a_t` 和任务指令 `l` 的编码进行**跨模态融合**。
    - 通过多头任务学习同时输出三个预测：
        - **动作成功概率** `ŷ_suc` ∈ [0, 1]
        - **任务进展分数** `ŷ_prog` ∈ [-1, 1]
        - **错误类型** `ŷ_err` (成功、无操作、目标错误、页面错误、超时)
- **弱监督数据构建流程**:
    - **无需额外人工标注**，从现有GUI轨迹数据集中自动构建训练样本。
    - **正样本**：来自成功轨迹的连续动作对。
    - **负样本**：通过四种策略生成，包括动作错配（替换动作）、状态错配（替换截图）、无操作检测（`s_t` ≈ `s_{t+1}`）和失败轨迹采样。
    - 错误类型标签和进展分数的伪标签由启发式规则生成。
- **训练流程**：分两阶段进行，第一阶段为对比预训练，让模型学习对齐视觉差异与正确动作；第二阶段为多任务微调，联合优化成功概率、进展分数和错误类型三个目标。

- 论文提出的**弱监督数据构建流程**能够有效利用现有轨迹数据，为训练强大的视觉评判模型提供充足、低成本的训练样本。

### 7. 优点
- **范式创新**：首次明确指出并解决了GUI过程验证中的“模态失配”问题，提出了从文本验证转向视觉状态比较的新范式。
- **技术扎实**：设计精巧的孪生视觉差异编码器和变化区域注意力机制，能够从语义层面捕捉有意义的UI变化，鲁棒性强于像素差分。
- **通用性强**：作为即插即用模块，展现了对多种不同架构GUI智能体的良好兼容性和性能提升。

- **资源友好**：提出的数据构建流程无需额外人工标注，降低了数据获取成本；并探索了轻量化模型变体，考虑了实用性。

### 8. 不足与局限
- **视觉理解天花板**：性能受限于其骨干ViT编码器，对于微小文本变化或极其细微的UI状态转换（例如，计数器从“3”跳到“4”）的识别能力可能不足。
- **抗干扰能力**：虽然对噪声有一定鲁棒性，但任务无关的视觉动态（如动画、模态广告、异步加载）依然可能降低验证的准确性。
- **弱标签噪声**：数据构建流程依赖启发式规则和轨迹对齐来生成伪标签，这在训练数据中引入了标签噪声。
- **平台泛化**：训练数据主要来自网页和移动端，虽然在桌面端（OSWorld）测试了零样本能力，但其在该新平台上的性能提升相对较小，更优的跨平台泛化仍是一个挑战。
- **轻量化与性能的权衡**：虽然提供了更小的模型变体，但其性能仍有所折损，如何极致压缩模型同时保持高性能是未来方向。
