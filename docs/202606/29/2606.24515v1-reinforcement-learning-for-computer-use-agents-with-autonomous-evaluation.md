## 摘要
计算机使用智能体（CUA）通过在图形用户界面中直接感知和操作来执行高级用户目标。然而，针对CUA的强化学习仍然困难，因为开放的桌面环境很少提供可扩展的、机器可读的奖励信号：任务成功通常基于视觉，难以通过人工设计的奖励函数或密集手工标注来指定。我们提出一种RL微调框架，利用自主视觉-语言评估作为GUI智能体的可扩展监督信号。给定最终截图和原始指令，视觉-语言模型判断任务完成情况，并在策略优化期间提供终端反馈，无需任务特定启发式或人工标注。由于自主评估器并非完美，我们将其反馈建模为带噪声的二值奖励通道，并为近端策略优化推导了噪声校正奖励估计器。在macOSWorld、Windows Agent Arena和OSWorld上的实验表明，校正后的评估器奖励优于零样本基线和原始评估器奖励，相较于零样本性能平均提升12.6个百分点，相较于原始评估器微调提升5.1个百分点。这些结果表明，当显式建模并校正评估器噪声时，自主评估可作为GUI环境中RL的实用奖励信号。

## Abstract
Computer-Use Agents (CUAs) execute high-level user goals by perceiving and acting directly within graphical user interfaces. However, reinforcement learning for CUAs remains difficult because open-ended desktop environments rarely provide scalable, machine-readable reward signals: task success is often visually grounded and hard to specify with handcrafted reward functions or dense manual labels.   We propose an RL fine-tuning framework that uses autonomous vision-language evaluation as a scalable supervision signal for GUI agents. Given a final screenshot and the original instruction, a Vision-Language Model judges task completion and provides terminal feedback without task-specific heuristics or manual labels during policy optimization.   Because autonomous evaluators are imperfect, we model their feedback as a noisy binary reward channel and derive a noise-corrected reward estimator for Proximal Policy Optimization. Experiments across macOSWorld, Windows Agent Arena, and OSWorld show that corrected evaluator rewards outperform both zero-shot baselines and raw evaluator rewards, improving success rates by an average of 12.6 percentage points over zero-shot performance and 5.1 points over raw evaluator fine-tuning. These results suggest that autonomous evaluation can serve as a practical reward signal for RL in GUI environments when evaluator noise is explicitly modeled and corrected.

### 2. 论文提出的方法论
*   **核心思想**：将自主评估器的输出视为一个二值噪声信道（可能产生假阳性/假阴性），通过统计模型估计错误率，并推导出一个渐近无偏的校正奖励估计器，直接代入近端策略优化（PPO）进行策略更新。

    *   **噪声建模**：定义假阴性率 $e_+$ 和假阳性率 $e_-$，可分离性 $D = 1 - e_+ - e_- > 0$ 以保证评估信号优于随机猜测。
    *   **奖励校正**：基于期望关系 $E[\tilde{r} | r^*] = e_- + D \cdot r^*$，导出校正奖励 $\hat{r} = \frac{\tilde{r} - e_-}{D}$，在终端才给出，满足 $E[\hat{r} | \tau] = r^*$。
    *   **参数估计**：从留出的校准任务集（不与训练集重叠）估计 $\hat{e}_+$、$\hat{e}_-$ 和 $\hat{D}$，得到插件式估计器 $\hat{r}^\sharp = \frac{\tilde{r} - \hat{e}_-}{\hat{D}}$。
    *   **策略优化**：采用PPO，将校正后的终端奖励 $\hat{r}$ 作为返回值，在轨迹末端反向传播优势估计，实现带有噪声校正的策略梯度更新。

### 6. 论文的主要结论与发现
*   自主 VLM 评估能够作为稀疏终端奖励信号，有效微调计算机使用智能体，在所有基准上均超过零样本表现。
*   显式校正评估器噪声（尤其是假阳性和假阴性）能显著提升 RL 成功率：噪声校正奖励相较于原始评估奖励，平均提高 5.1 个百分点；相较于零样本基线，平均提高 12.6 个百分点。

*   忽略评估器噪声会引入偏差，在某些场景下反而会降低迁移性能（如 OSWorld 上原始奖励效果不佳），验证了噪声建模的必要性。

*   **无需人工标注**：框架完全不依赖人工成功标签或任务特定启发式，有利于大规模扩展。
*   **通用性强**：方法同时适用于 macOS、Windows、Linux，且使用多个外部数据集，展示了良好的跨平台、跨任务场景的适用性。

### 8. 不足与局限
*   **评估器非平稳性**：假阳性和假阴性率可能因任务类型、UI 变化、智能体自身改进导致的分布偏移而发生变动，静态的全局校正不够鲁棒。
*   **信号稀疏**：仅使用终端二值奖励，长时程任务面临探索困难，方法本身不解决奖励密度问题。
*   **校准依赖**：校正效果依赖于校准集的质量和大小，小样本下估计方差大，尤其当可分离性 D 较小时会放大噪声。
*   **奖励范围变化**：校正后的 $\hat{r}$ 可能超出 [0, 1]，影响价值函数规模和 PPO 稳定性；虽在期望上不变，但实际训练中仍需精细调参。
*   **评估器盲区**：视觉模型可能忽略语义正确但视觉上不明显的成功状态，或根据表面视觉线索误判，且二值评分忽略了任务部分完成或替代性有效方案。
*   **分布泛化未深入测试**：对不同应用版本、屏幕分辨率、无障碍设置等更广泛的分布偏移，鲁棒性仍待研究。
