## 摘要
机器人操控的强化学习通常需要手动设计密集奖励函数，这难以调节且往往脆弱，或需从人类演示或偏好中学习奖励，代价高昂。近期工作利用预训练的视觉语言模型（VLM）作为零样本奖励模型，以单一文本提示取代这些成本。然而，我们认为，对于初始条件随机的长时域操控任务，单一全局提示过于粗糙。单提示VLM奖励在轨迹大部分区域几近平坦，使智能体难以察觉早期进展。我们提出强化微任务学习（RMTL），该方法将操控任务分解为一小组语言描述的微任务，并训练智能体在它们之间切换。每一步，智能体接收多视角VLM奖励，该奖励使用当前活动微任务的提示计算，并跨多个相机视角取均值，以减少特定视角遮挡的影响。通过反向课程逐步让智能体接触更难的初始条件，同时先使用固定的基于距离的规则训练一个PPO工作者来选择活动微任务。然后，我们用学习得到的分层管理器替换此规则，将基于规则的阶段选择转变为完全学习的分层策略。我们在Fetch操控环境中用三个简短的阶段特定提示实例化RMTL，无需额外提示调优。实验表明，RMTL比单提示VLM奖励提供更具信息性的奖励信号，实现更快学习。这些结果表明，将VLM奖励分解为微任务特定的语言提示可显著提升语言引导的强化学习在机器人操控中的可扩展性。

## Abstract
Reinforcement learning (RL) for robotic manipulation often requires manually designing a dense reward function, which is difficult to tune and often fragile, or learning a reward from human demonstrations or preferences, which can be expensive. A recent line of work uses pretrained vision-language models (VLMs) as zero-shot reward models, replacing these costs with a single text prompt. However, we argue that a single global prompt is too coarse for long-horizon manipulation tasks with randomized initial conditions. The single-prompt VLM reward is near-flat for much of the trajectory, making early progress hard for the agent to detect. We propose Reinforced Micro-Task Learning (RMTL), an approach that decomposes a manipulation task into a small set of language-described micro-tasks and trains the agent to switch between them. At each step, the agent receives a multi-view VLM reward computed using the prompt of the currently active micro-task and averaged across multiple camera views to reduce the effect of view-specific occlusions. A reverse curriculum gradually exposes the agent to harder initial conditions, while a PPO worker is first trained with a fixed distance-based rule that selects the active micro-task. We then replace this rule with a learned hierarchical manager, turning rule-based phase selection into a fully learned hierarchical policy. We instantiate RMTL on the Fetch manipulation environment using three short stage-specific prompts and without additional prompt tuning. Experiments show that RMTL provides more informative reward signals than single-prompt VLM rewards, enabling faster learning. These results suggest that decomposing VLM rewards into micro-task-specific language prompts can substantially improve the scalability of language-guided reinforcement learning for robotic manipulation.

- **研究动机**：机器人长时域操控任务（如从随机起始位姿抓起物体）的奖励设计极为困难。手工设计密集奖励依赖特权状态信息且脆性大；从人类示教/偏好学习奖励成本高。近期工作使用预训练视觉语言模型（VLM）通过单一文本提示生成零样本奖励，但存在“单提示失效”问题。
- **核心问题**：单一全局提示（如“机器人夹爪提起红色方块”）对长时域操控产生的 VLM 奖励信号近乎平坦——在轨迹初期，夹爪位置远离最终目标图像配置，嵌入相似度几乎不变，导致强化学习（RL）智能体无法检测早期进展、信用分配困难、探索失效。
- **整体含义**：提出 **RMTL（Reinforced Micro-task Learning）**，将操控任务分解为一小段语言描述的微任务（如“接近”、“对准”、“抓取”），为各阶段生成密集、有变化的 VLM 奖励，从而显著提升语言引导 RL 在机器人操控中的可扩展性。

## 2. 方法论

### 2.1 核心思想

- **微任务分解**：将长时域任务划分为 \(K=3\) 个逻辑阶段，每个阶段对应一个短文本提示（例如“打开的夹爪对正红色方块上方”），由冻结的 VLM 根据当前活动微任务计算奖励。
- **多视角聚合**：渲染 \(V=6\) 个固定相机视角，分别计算每个视角的 VLM 语义得分，取算术平均作为最终奖励，降低单视角遮挡噪声。
- **反向课程**：从易到难逐步扩大初始夹爪位置的随机范围，仅在当前难度成功率达到阈值时才进入下一阶段，避免早期完全随机引发梯度消失。
- **分层控制**：先使用基于距离的规则选择活动微任务训练 PPO 工作者（Stage 1）；再用一个学习得到的轻量级管理器（MLP）取代规则，通过 REINFORCE 优化管理器策略，形成完全学习的分层策略（Stage 2）。

### 2.2 关键技术细节

- **VLM 奖励计算**：使用冻结的 PE-Core-bigG-14-448 模型。预计算基线提示 \(b\) 和各微任务目标提示 \(\tau_i\) 的文本嵌入。对微任务 \(i\)，定义语义位移方向 \(d_i = e_{\tau_i} - e_b\)，并引入投影混合矩阵 \(P_\alpha(d_i)\) 以平衡沿方向奖励与无限制余弦相似度：
  \[
  P_\alpha(d_i) = \alpha \frac{d_i d_i^\top}{\|d_i\|_2^2} + (1-\alpha)I
  \]
  单视角奖励为 \(r^{(i)}_v = 1 - \frac12 (x_v - e_{\tau_i})^\top P_\alpha(d_i) (x_v - e_{\tau_i})\)，多视角聚合后输出 \(r^{(i)}_t = \frac1V \sum_v r^{(i)}_v\)。取 \(\alpha=0.9\) 以增大奖励数值范围。
- **Stage 1：PPO 工作者 + 规则选择器**：三步规则：根据夹爪‑方块距离划分为三个区间（\(<0.04\)m 对准，\(0.04\)‑\(0.15\)m 接近，\(>0.15\)m 对齐）。工作者接收当前活动微任务的奖励进行 PPO 更新。
- **Stage 2：学习管理器**：一个 MLP（[128,128]），以状态为输入输出三个微任务的选择。**预热**：先通过行为克隆（BC）用规则标签进行 3500 步监督训练。**在线训练**：每 \(H=3\) 步由管理器以 \(\epsilon\)-greedy (\(\epsilon=0.2\)) 选择一个微任务，PPO 工作者据此行动。管理器用 REINFORCE（基于片段回报的标准化优势）进行更新，同时加入熵奖励和 KL 散度锚定（至规则策略）以保持稳定。工作者初始加载 Stage‑1 560k 步检查点，前 50k 环境步冻结演员网络，仅训练评论家以减少管理器训练早期的非平稳性；之后解冻且降低学习率。
- **反向课程**：5 个难度等级（\(d\in\{0,0.15,0.4,0.65,1.0\}\)），分别限制初始夹爪位姿的随机范围，由在线成功率门控升级，最终阶段进行完全随机初始化。

## 6. 主要结论与发现

1. **微任务提示是关键**：将单一全局提示分解为 3 个阶段提示，使原本近乎平坦的 VLM 奖励变为分段单调信号，PPO 能从中提升；单一全局提示在随机初始化下无法收敛，而微任务提示达到约 89% 成功率。
2. **多视图聚合**：平均 6 个视角的 VLM 分数比任何单一视角都平滑，减少了遮挡引出的噪声，且不损害梯度形态。
3. **反向课程是必要粘合剂**：没有课程的情况下，语言奖励在完全随机初始化时信息量过低，无法启动探索（图6）。
4. **学习管理器优于规则**：用规则进行 BC 热启动后，学习得到的管理器成功率从 94% 提升至约 98%，且与规则决策的协议率为 73%，表明规则提供了良好的归纳偏置，而学习能突破其瓶颈。
5. **整体**：RMTL 提供了一个利用冻结 VLM 获得密集、阶段性奖励的实用方案，无需手写特权状态奖励或大量演示数据，三个简洁的提示即可驱动学习。

## 7. 优点

- **无需手动奖励工程**：直接利用预训练 VLM 作为零样本奖励源，仅需给出自然语言微任务提示，极大降低了奖励设计的门槛。
- **信号密集且可学**：微任务分解将单一平坦奖励转化为阶段性有梯度的奖励，使 PPO 能高效学习长时域任务。
- **鲁棒性设计**：多视角聚合对抗遮挡，反向课程保证探索成功，分层管理器利用规则热启动并进一步优化，整体 pipeline 设计严谨。
- **可解释性强**：微任务提示与阶段切换高度可解释，管理器的决策可对照物理规则检验（73% 协议率）。
- **算力友好**：单 A100 GPU、6 百+ 2 百万步内收敛，适合实验室规模复现。

## 8. 不足与局限

- **依赖 VLM 感知能力**：奖励信号受 VLM 内在限制，光照、材质、遮挡等可能产生噪声；VLM 缺乏细粒度空间推理，接触密集阶段奖励模糊；目标附近奖励易饱和导致梯度消失。
- **视觉域差距处理**：需要针对 Fetch 环境专门设计高保真渲染（红色方块、木纹桌面），泛化到新环境或真实机器人可能需额外适配。
- **提示仍需手动设计**：目前微任务分解和提示由人工定义，虽然仅 3 句，但扩展到更多种类任务仍需要手动介入。文中已展望用 LLM 自动拆解。
- **任务单一**：仅在 FetchPickAndPlace‑v4 上实验，未展示其他操控任务或更复杂场景的迁移。
- **管理器与工作者联合训练**：当前采用分阶段训练（先冻工作者训管理器，后联合微调），从零开始的端到端分层学习尚未探索。
- **未与其他基于演示/偏好的奖励学习方法进行对比**，仅比较单一 VLM 奖励的变体，缺少与稀疏奖励、手工稠密奖励或 Live、RT‑1 等方法的直接对比。
