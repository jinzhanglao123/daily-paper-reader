## 摘要
迭代式生成建模技术，如流匹配，为有效的离线强化学习提供了强大的工具来建模复杂行为。在这项工作中，我们提出了一种新的异策略强化学习算法，该算法基于先验数据训练流策略。我们的思路始于“扩展”马尔可夫决策过程框架，该框架将个体流细化步骤视为马尔可夫决策过程中的单独动作。为了在该框架内实现异策略强化学习，我们应用了两种技术：我们生成虚拟同策略轨迹（通过“逆向”流）以使该框架与先验数据兼容，并应用了一种偏差-方差减少技术以缓解异策略强化学习中的时间跨度诅咒。我们将所得算法称为逆向Q学习（RQL）。与先前的基于流的强化学习方法相比，RQL具有几个优势：它不受随时间反向传播的困扰，更好地利用了学习到的价值函数，并直接训练完整的、富有表现力的流策略。通过在50个具有挑战性的模拟机器人任务上的实验，我们表明，与最先进的基于流的离线强化学习算法相比，RQL取得了最佳的离线强化学习平均性能。

## Abstract
Iterative generative modeling techniques, such as flow matching, provide powerful tools to model complex behaviors for effective offline reinforcement learning (RL). In this work, we propose a new off-policy RL algorithm that trains a flow policy based on prior data. Our idea starts from the "expanded" Markov decision process (MDP) framework, which treats individual flow refinement steps as separate actions in an MDP. To enable off-policy RL within this framework, we apply two techniques: we generate virtual on-policy trajectories (by "reversing" flows) to make this framework compatible with prior data, and we apply a bias-and-variance reduction technique to mitigate the curse of horizon in off-policy RL. We call the resulting algorithm Reversal Q-learning (RQL). RQL has several advantages over previous flow-based RL methods: it does not suffer from backpropagation through time, makes better use of the learned value function, and directly trains the full, expressive flow policy. Through our experiments on 50 challenging simulated robotic tasks, we show that RQL leads to the best average offline RL performance compared to state-of-the-art flow-based offline RL algorithms.

## 1. 论文的核心问题与整体含义

- **研究背景**：近年来，迭代生成模型（特别是流匹配，flow matching）在离线强化学习（offline RL）中表现出强大的行为建模能力，能够学习多模态、富有表现力的动作分布。但将这类迭代模型用于异策略（off-policy）RL训练仍面临根本困难。
- **核心问题**：现有的基于扩散或流策略的离线RL方法主要依赖三种范式，但各有严重局限：
  - **时间反向传播（BPTT）**：对迭代生成过程进行梯度传导，导致训练不稳定和次优性能。
  - **回归/拒绝采样**：仅使用价值函数的零阶信息（无梯度），性能受限或计算开销极大。
  - **扩展MDP（Expanded MDP）框架**：将每一步去噪/流迭代视为单独的MDP步骤，避免了BPTT并可以利用价值梯度，但直接用于离线RL面临两个挑战：
    1.  离线数据集不包含扩展MDP中的中间流轨迹；
    2.  有效的MDP时间跨度（horizon）被放大*F*倍（*F*为流迭代步数），加剧异策略RL中的“时间跨度诅咒”。
- **整体含义**：本文提出一种新的异策略流RL算法RQL（Reversal Q-Learning），通过**流的可逆性**和**确定性**生成虚拟同策略轨迹，并配合**无偏零方差的multi-step回报**来缩减有效时间跨度，从而在扩展MDP框架内实现高效、稳定的流策略离线训练。

## 2. 方法论

核心思想是利用流匹配ODE的可逆性（逆向流）为离线数据中的每一个状态-动作对生成对应的完整流轨迹（虚拟同策略轨迹），并在此基础上应用直接跳到流轨迹末尾的multi-step TD学习，从而将平均有效时间跨度从 *T × F* 降回 *T*。

### 2.1 扩展MDP及虚拟轨迹生成
- 给定原始MDP *M = (S, A, r, μ, p)*，构建扩展MDP \(\tilde{M} = (\tilde{S}, A, \tilde{r}, \tilde{\mu}, \tilde{p})\)，其状态由环境状态 *s*、部分生成的动作 *x* 和离散流时间 *f* 组成。
- 动作仍是速度向量增量，环境每 *F* 步更新一次真实状态并给与奖励。
- 针对离线数据集中每个转移元组 *(s, a, r, s')*，利用**逆向流ODE**：
  \[
  \frac{d}{df} \theta(s, x, f) = -v(s, \theta(s, x, f), f)
  \]
  通过欧拉法从 *x_F = a* 逆向求解出 *x_{F-1}, …, x_0*，从而得到一条完整的、基于当前流策略的“虚拟”同策略流轨迹，构成扩展MDP的虚拟数据集 \(\tilde{D}\)。

### 2.2 价值函数学习：有效时间跨度缩减
- 对虚拟轨迹，直接使用**无偏且零方差的multi-step回报**来跳过中间流步：
  \[
  L(V) = \mathbb{E}_{\tilde{\tau}} \left[ \ell_2^{\kappa} \big( V(s, x_f, f) - (r + \gamma V(s', x'_0, 0)) \big) \right]
  \]
  其中目标的下一状态直接从流轨迹末尾（真实环境下一状态及从先验重新采样的 *x'*）取值，不再需要经过 *F* 步的中间Bellman备份。
- 此处用**期望分位损失（expectile loss）**隐式地近似 max 算子（类似 IQL 变体），避免显式最大值查询带来的OOD问题。
- 该方法将平均有效时间跨度从 *T × F* 降至 *T*，极大缓解了异策略RL中的长视界偏差积累。

### 2.3 策略学习
- 采用类似DDPG的确定性策略梯度形式，并加入行为正则化：
  \[
  L(v) = -\mathbb{E}_{\tilde{\tau}} \left[ V(s, x_f + v(s, x_f, f), f+1) \right] + \alpha L_{\text{BC}}(v)
  \]
  其中 \(L_{\text{BC}}\) 为标准流匹配损失，促使流策略保持与离线数据行为分布接近。这种设计使策略既能最大化价值，又能从数据中提炼行为先验，并稳定逆向过程。

### 2.4 算法实现细节
- 实际使用**动作分块（action chunking）**，同时处理多个未来动作。
- 价值网络使用集成（ensemble），并引入悲观系数 \(\rho\) 提升离线稳定性。
- 评估时采用策略的指数滑动平均（EMA）。

## 6. 主要结论与发现

- **性能优势**：RQL在50个任务中取得**最高平均性能**（56分 vs 最强基线46分），尤其在长视距任务（如antmaze-giant, humanoidmaze-large, puzzle-4x4, cube-quadruple）上优势显著。
- **组件有效性**：
  - 去除有效时间跨度缩减的TFQL性能严重下降，甚至有部分任务完全失败，证明该技术是必需的。
  - 高κ值（更偏向“最大化”）普遍带来更好性能，说明数据集的行为通常是次优的。
  - α 是重要的调节参数，需根据任务特性调整。
- **范式优势**：RQL成功避开了BPTT的不稳定性，同时通过利用价值函数一阶梯度信息，优于纯零阶（回归/拒绝采样）方法。

## 7. 优点

- **创新性**：巧妙利用流匹配的确定性及可逆性，将离线数据转换为虚拟同策略轨迹，使扩展MDP框架首次在离线RL中高效可行。
- **理论吸引力**：multi-step回报在此构造下是无偏且零方差的，避免了常规异策略multi-step学习的偏差-方差权衡。
- **性能突出**：在大量多样任务上全面领先现有流策略离线RL算法，尤其适合长视距挑战。
