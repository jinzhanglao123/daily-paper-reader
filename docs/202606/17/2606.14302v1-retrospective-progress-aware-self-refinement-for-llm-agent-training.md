## 摘要
基于大语言模型的智能体通过强化学习训练优化逐步动作预测，但缺乏对任务进度的元认知意识，导致阻碍长时域扩展的差距。初步研究表明，在线进度提示会损害性能，而回顾性演示则有所帮助，但仅凭结果奖励训练无法产生这种能力。我们提出RePro，即回顾式进度感知训练框架，该框架通过先行动后反思的展开范式训练智能体自我生成进度信号：智能体在线执行动作，然后在给定完整轨迹和已知结果的情况下，回顾性地重新评估其逐步进度。RePro从回顾预热开始，通过最少的外部演示教授反思格式，然后通过RePro-PO进一步训练，采用复合奖励产生自我生成的信号，无需持续的外部监督。在WebShop、ALFWorld和Sokoban上的实验表明，RePro提升了Qwen家族的性能，绝对成功率增益高达12%。

## Abstract
LLM-based agents trained with reinforcement learning optimize step-wise action prediction but lack metacognitive awareness of task progress, inducing a gap that hinders long-horizon scaling. A pilot study reveals that online progress prompting hurts performance while retrospective demonstrations help, yet this capability cannot emerge from outcome-reward training alone. We present RePro, Retrospective Progress-Aware Training, a framework that trains agents to self-generate progress signals via a forward-then-reflect rollout paradigm: the agent executes actions online, then retrospectively reassesses its step-wise progress given the completed trajectory and known outcome. RePro initializes with a Retrospection Warmup that teaches reflection format from minimal external demonstrations, then further trains through RePro-PO with a composite reward that produces self-generated signals without continuous external supervision. Experiments on WebShop, ALFWorld, and Sokoban show that RePro enhances the Qwen family's performance, with up to $12\%$ absolute success rate gains.

### 核心问题与研究动机

- **核心问题**：基于大语言模型（LLM）的智能体在长时域任务中通过强化学习（RL）优化逐步动作预测，但普遍缺乏对任务进度的元认知意识。这使得智能体难以感知“已完成什么、还剩什么、当前路径是否正确”，从而限制了模型在长序列任务中的可扩展性。
- **初步发现（pilot study）**：在 WebShop 环境上的受控实验表明，要求智能体在线输出进度估计会显著降低任务成功率（平均下降 8.6%），而提供基于完整轨迹与结果的回顾性进度演示则能带来明显提升（平均提高 7.9%）。这种不对称性说明进度信息本身有益，但仅靠即时提示无法可靠获得，必须通过专门训练从回顾性轨迹中学习进度评估能力。

### 方法论：回顾式进度感知训练（RePro）

- **整体思想**：让智能体先前向执行任务并在线给出进度估计，任务结束后再根据完整轨迹和最终结果回顾性地重新评估每一步的真实完成进度，并通过这一自生成的回顾进度信号辅助 RL 训练。
- **两阶段框架**：
  - **前向-反思（Forward-then-Reflect）范式**：每一步智能体在产生动作的同时输出一个在线进度评估 \~p_t；轨迹完成后，利用完整的交互历史与最终奖励，让模型切换至“回顾模式”输出每一步的回顾进度 p_t，以此作为后续训练的监督信号。
  - **回顾预热（Retrospection Warmup）**：利用外部大模型（DeepSeek-V4）对少量成功轨迹生成回顾性进度演示，构造有监督微调数据集 D_warmup，对智能体进行初步微调，使其掌握回顾反思的输出格式。
  - **RePro-PO 阶段**：在预热基础上，使用带复合奖励的策略优化进行强化学习。每一步奖励不仅包含环境给出的稀疏结果奖励，还集成了：
    - **进度塑造奖励** `rp(t) = β·(p_{t+1} - p_t)`：鼓励回顾进度的正向增量变化。
    - **对齐奖励** `ralign(t) = (1/T)α·max(0, 1-|p_t - \~p_t|)`：拉近在线估计与回顾进度的距离。
    - **格式正则化奖励**：惩罚格式不合规（如 p_1 ≠ 0 或成功时 p_T ≠ 1）。
  - 采用 GiGPO 的双层级优势估计：回合级别优势（整体回报归一化）和步骤级别优势（比较相同锚点状态下不同动作的折现回报差异），联合优化策略。

### 主要结论与发现

- **进度感知不能自然涌现**：即使显式提示，标准结果导向训练也无法让智能体学到有效的进度意识，甚至可能因在线估计误差损害性能。
- **RePro 显著提升长时域任务成功率**：在 WebShop 上相较于 Meta Prompt 基线，1.5B 模型绝对成功率提升 8.98%，3B 提升 11.57%，7B 提升 5.82%；在 ALFWorld 和 Sokoban 上也取得一致增益（如 ALFWorld 1.5B 提升 11.72 SR，Sokoban 4B 提升 3.12 SR）。
- **回顾进度信号质量高**：RePro 训练出的模型在“中间判别力”指标上远超基线（成功与失败轨迹的最终进度之差更大），且进度预测表现出更好的单调性和较低的平台/衰减率，能有效区分成败轨迹。
- **预热与 RL 联合至关重要**：仅靠监督式预热无法习得有效进度意识，而去除预热则训练不稳定；回顾反射和复合奖励机制超越了简单的格式初始化和奖励重整形。

### 优点

- **新颖的元认知信号设计**：通过“先执行后反思”的范式，将结果反馈转化为步骤级自监督进度信号，实现了不需要外部奖励模型或密集人工标注的中间监督。
- **框架完整且可复现**：两阶段训练（格式预热 + 复合奖励 RL）可插入现有策略优化框架，实验覆盖多环境、多模型规模，消融细致。
- **进度质量量化系统性强**：针对无真实进度标注的场景，设计了一组基于行为性质和结果对齐的评估指标，较为巧妙地衡量了进度信号的有效性。
- **性能增益明显且一致**：在多个不同类型的长时域任务上均取得稳定提升，验证了方法的通用性。

### 不足与局限

- **进度表示形式单一**：仅采用语言化的数值进度估计，未探索潜在状态或隐向量监督等更高效的形式。
- **环境覆盖有限**：仅在 WebShop、ALFWorld 和 Sokoban 三个中等复杂度的文本/简单网格环境上验证，未扩展到 GUI 操作、具身交互等更复杂、更贴近现实的长时域场景。
- **进度标签缺少真实标定**：回顾进度实际由模型自身或外部 LLM 生成，并非基于真实中间状态，可能存在偏差；未来可利用人工标注或更强模型评估作为伪金标准来校准。
- **算力细节缺失**：未报告 GPU 型号、训练时长等资源消耗数据，不便直接复现成本评估。
