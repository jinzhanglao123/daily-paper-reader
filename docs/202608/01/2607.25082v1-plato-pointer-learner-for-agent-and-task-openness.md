## 摘要
开放智能体系统（OASYS）在智能体和任务集合随时间不可预测变化的现实世界领域中日益普遍。这种开放性，包括智能体开放性（AO）和任务开放性（TO），给多智能体强化学习（MARL）带来了根本性挑战，因为MARL通常假设固定的状态和动作空间。现有方法仅部分解决了开放性问题：填充和掩码方法引入了人为界限，而最近的基于图或超图的方法处理了开放性的一个维度，但仍依赖于限制性假设。在本文中，我们提出了面向智能体与任务开放性的指针学习器（PLATO），这是一种基于指针网络的行动者，与集中式图神经网络批评者相结合，在集中训练分散执行的范式下使用多智能体近端策略优化进行训练。我们的基于指针的行动者直接输出当前任务集合上的分布。这直接支持变化的动作空间，无需掩码或重新训练。我们的图神经网络批评者将智能体-任务交互编码为一个随任务和智能体组成而改变形状的图。这些组件共同考虑了AO和TO，而无需现有方法的界限性。我们在任务与智能体开放马尔可夫博弈（TaAgO-MG）中形式化了PLATO，扩展了先前的任务开放公式，并证明了它在由此产生的无界状态和动作空间上是良定义的。我们使用开放智能体系统评估倡议的方法（MOASEI）野火抑制领域评估PLATO，这是一个专为开放多智能体系统评估设计的环境，并展示了在OASYS中比最先进基线更强的性能和更一致的零样本泛化能力。

## Abstract
Open agent systems (OASYS) are increasingly prevalent in real-world domains where the sets of agents and tasks change unpredictably over time. Such openness, including agent openness (AO) and task openness (TO), poses a fundamental challenge to multi-agent reinforcement learning (MARL), which typically assumes fixed state and action spaces. Existing methods address openness only partially: padding and masking approaches introduce artificial bounds, while recent graph-based or hypergraph methods handle one dimension of openness but still depend on restrictive assumptions. In this paper, we introduce Pointer Learner for Agent and Task Openness (PLATO), a pointer-network-based actor combined with a centralized graph neural network (GNN) critic, trained with multi-agent proximal policy optimization under a centralized training and decentralized execution paradigm. Our pointer-based actor outputs distributions directly over the current task set. This directly supports changing action spaces without masking or retraining. Our GNN critic encodes agent-task interactions as a graph that changes shape with task and agent composition. Together, these components consider AO and TO without the boundedness of existing approaches. We formalize PLATO in a Task-and-Agent-Open Markov Game (TaAgO-MG), extending prior task-open formulations, and prove it is well-defined over the resulting unbounded state and action spaces. We evaluate PLATO with the Methods for Open Agent Systems Evaluation Initiative (MOASEI) wildfire suppression domain, an environment designed for open multi-agent system evaluation, and we demonstrate strong performance and more consistent zero-shot generalization than state-of-the-art baselines in OASYS.

- **PLATO架构概览**：基于中心化训练与分散执行（CTDE），包含两个核心组件：
    - **指针行动者（Pointer Actor）**：分散时使用的策略网络，直接对当前任务集输出动作分布。
    - **GNN批评者（GNN Critic）**：只在训练时使用，以二部图编码全局状态，评估值函数。
- **指针行动者细节**：
    - **观察分解**：将每个智能体的局部观察分解为智能体特征矩阵 \(o^t_N\) 和任务特征矩阵 \(o^t_X\)。
    - **智能体编码（处理AO）**：对 \(o^t_N\) 计算均值、方差、最小值、最大值四类统计量，得到一个固定长度的描述向量 \(d^t\)，再经MLP生成查询向量 \(q^t\)；该编码对智能体顺序置换不变。
    - **任务编码（处理TO）**：对每一个任务的特征（外加一个常驻的NO‑OP）独立使用MLP生成键向量 \(k^t_x\)。
    - **指针解码**：通过加性注意力计算查询与每个键的兼容性分数 \(u^t_x = v^\top \tanh(W_K k^t_x + W_q q^t)\)，再经softmax得到当前任务集合上的分类分布。动作支持集随任务出现/消失而自动伸缩，无需掩码。
- **GNN批评者细节**：
    - 将全局状态表示为二部图 \(G^t = \langle X^t, N^t, E^t \rangle\)：任务节点、智能体节点，智能体与可执行任务间存在边。

### 3. 实验设计
- **评测环境**：MOASEI倡议下的**野火抑制领域**。网格地图上消防员（智能体）位置固定，火点（任务）具有不同大小，可通过围剿被扑灭；火势会内生蔓延（endogenous TO）或随机点燃（exogenous TO），消防员耗尽灭火剂后需退出并补充（AO）。
- **实验设定**：在 \(2\times 3\)、\(3\times 3\)、\(4\times 4\) 三种网格上测试四种开放程度配置：

    - S3：双重开放+严重智能体约束（蔓延概率0.6，随机点火概率0.6，补充概率仅0.6）。
- **对比方法**：
    - 三种有学习能力且与开放相关的基线：**DGN**（图卷积强化学习）、**DICG**（深度隐式协调图）、**MOHITO**（专为TO设计的超图方法）。

- **泛化测试**：**零样本（zero-shot）**将训练好的策略直接部署到未见过的大网格（如\(2\times 3 \to 3\times 3, 4\times 4\)；\(3\times 3 \to 4\times 4, 5\times 5\)），不进行任何微调。

- **严格的实证方法论**：全面调优、等种子评测、适应正态性检验、多重比较校正，结果可信度高。

### 8. 不足与局限
- **动作空间简化假设**：当前TaAgO‑MG设定中每个任务仅对应一个动作（如“扑灭该火”+NO‑OP），不支持每个任务具有多个关联动作（如浇水/砍隔离带等），限制了更复杂任务建模。
- **全可观性假设**：PLATO假设智能体局部观察中能够完全感知当前所有可达的智能体和任务，尚未扩展到部分可观场景。
- **领域有限**：仅在野火抑制一个领域进行评估，虽然这是OASYS的标准评测环境，但缺乏其他类型领域（如物流、搜救）的验证。
- **尚未覆盖框架开放性**：论文仅处理AO和TO，未涉及智能体内部目标/能力变化的“框架开放性（FO）”。
- **训练成本仍较高**：虽然单一运行仅需数天CPU，但总计近万CPU‑日的消耗对资源有限的研究者仍是门槛。
