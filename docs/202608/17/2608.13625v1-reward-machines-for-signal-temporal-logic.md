## 摘要
信号时序逻辑（STL）为指定实值观测的实时性质提供了一种形式化语言，并提供了用于监测满足程度的定量鲁棒性分数。随着现实世界系统复杂性日益增加，手工控制器设计变得不可行，因此从STL规范进行控制综合受到关注。此外，许多现代自主系统和人工智能赋能的系统缺乏准确且完整的系统模型，这使得基于优化的综合方法不适用，并推动了基于学习的控制。先前的工作将STL鲁棒性分数用作强化学习（RL）中的奖励，以获得满足给定规范的控制策略；然而，鲁棒性依赖于执行历史，对于具有任意嵌套时序算子的一般长时域规范，这会导致难以处理的状态空间扩展。本文引入一种新颖的基于自动机的方法，提供高效的记忆机制以及适用于RL框架的相关马尔可夫奖励。我们的方法从给定的STL规范构造时间交替自动机，利用自动机位置和时钟估值增广状态空间，并从自动机接受条件中导出奖励。我们通过实验证明，与使用基于鲁棒性奖励的现有方法所学到的策略相比，我们的方法所学到的策略获得了更高的鲁棒性分数和满足率。

## Abstract
Signal temporal logic (STL) provides a formal language for specifying real-time properties of real-valued observations, along with a quantitative robustness score for monitoring satisfaction. Control synthesis from STL specifications is of interest since manual controller design becomes infeasible as real-world systems grow in complexity. Moreover, many modern autonomous and AI-enabled systems lack accurate and complete system models, which makes optimization-based synthesis approaches unsuitable and motivates learning-based control. Prior work uses STL robustness scores as rewards in reinforcement learning (RL) to obtain control policies satisfying given specifications; however, robustness depends on execution history, leading to intractable state space expansion for general long-horizon specifications with arbitrarily nested temporal operators. This work introduces a novel automata-based approach that provides an efficient memory mechanism and associated Markovian rewards suitable for RL frameworks. Our approach constructs a timed alternating automaton from the given STL specifications, augments the state space with automaton locations and clock valuations, and derives rewards from the automaton acceptance condition. We empirically demonstrate that our approach learns policies that achieve higher robustness scores and satisfaction rates than those learned by existing approaches using robustness-based rewards.

## 1. 论文的核心问题与整体含义

- **核心问题**：如何在没有精确系统模型的情况下，从完整信号时序逻辑（STL）规范中高效学习控制策略，使其满足实时、连续信号上的时序约束。
- **研究背景与动机**：
  - STL 广泛用于描述机器人、交通、医疗等领域的实时性质，并可通过鲁棒性分数定量衡量满足程度。
  - 现代复杂自主系统往往缺少高保真模型，传统基于优化的控制综合难以适用，因此需要数据驱动的强化学习方法。
  - 现有 RL 方法大多直接用 STL 鲁棒性分数作为奖励，但鲁棒性依赖完整执行历史，破坏马尔可夫性，容易导致状态空间爆炸或学习不稳定。
  - 已有方法要么对完整历史进行状态增广、计算上不可扩展，要么只处理受限的 STL 片段，尚无支持完整 STL 且可扩展的无模型方法。
- **整体含义**：本文提出一种基于自动机的奖励机（STL-RM）方法，将 STL 转化为带时钟的自动机并用紧凑的自动机状态与时钟估值作为记忆，为 RL 提供马尔可夫奖励，从而在无模型设置下学习满足完整 STL 规范的策略。

## 2. 论文提出的方法论

- **系统建模**：
  - 将环境建模为半马尔可夫决策过程（SMDP），显式保留相邻观测之间的真实持续时间，以支持实时约束。
  - 采用事件基 STL 语义，语法包括谓词、否定、合取、带时间区间 `I` 的 until 算子，以及派生的 finally/globally 等算子。
- **自动机转换**：
  - 将给定 STL 规范翻译为单时钟交替时间自动机（OCATA），带有 Büchi 接受条件。
  - OCATA 支持析取（存在性/非确定性）与合取（普遍性/多线程）转移；时钟用于表达实时边界。
  - 自动机状态由位置 `l` 和时钟估值 `v` 组成，接受条件要求无限频繁访问接受位置。
- **STL 奖励机构造**：
  - STL-RM 定义为一个元组 `Rφ=(Q, q0, Δ, R)`。
  - 记忆列表 `Q` 中的每个条目包含：当前位置概率向量 `p` 和时钟估值 `v`；初始时仅一个条目位于初始自动机位置，概率为 1。
  - 转移函数更新机制：
    - 每次观测值先根据 CDF `h(μ(s))` 计算各谓词满足概率，再得到输入字母 `α` 的退化概率。
    - 析取分支由 RL 代理提供的 `ϵ` 动作选择；合取分支将父位置概率等分给子目标。
    - 若子目标带时钟重置，则创建新的记忆条目；若不停重置，则只更新概率分布。
    - 记忆列表容量设为 `N`，满时新条目及其概率被丢弃，相当于进入拒绝状态。
  - 奖励函数取所有条目中接受位置概率之和乘以缩放因子 `r`（如 0.1），因此奖励值在 `[0,1]` 之间。
- **产品 MDP**：
  - 将原 SMDP 与 STL-RM 组合为产品 MDP，状态由原状态、持续时间和记忆列表组成，动作包含环境动作与 `ϵ` 动作。
  - 在乘积空间中，奖励是马尔可夫的，可直接使用 PPO 等离策略/同策略 RL 算法。
- **理论保证**：
  - 若在产品 MDP 中取得最大期望回报 1，则对应原策略满足 STL 规范的概率为 1。
  - 该保证基于：回报为 1 当且仅当每一步所有概率质量都集中在接受位置，且没有条目被丢弃，从而满足 Büchi 条件。

## 3. 实验设计

- **任务规范**：
  - 使用三个基本子规范：
    - 顺序任务 `φsequencing = F(a1 ∧ F a2)`：先到达区域 `a1`，再到达区域 `a2`。
    - 稳定性任务 `φstability = G((a1∨a2) ⟹ F[0,T](b1∧b2))`：访问 `a1` 或 `a2` 后须在 `T=30` 个时间步内返回中央区域 `b1∧b2`。
    - 安全任务 `φsafety = G¬(c1∨c2)`：始终避开危险区域。
  - 两个任务变体：
    - `φpartial = φsequencing ∧ φsafety`：无界时序，只需逻辑顺序和安全。
    - `φfull = φsequencing ∧ φstability ∧ φsafety`：额外包含有界时间稳定性，需记忆事件发生的具体时间。
  - 所有谓词定义在一维信号 `x` 上，例如 `μa1(s)=x−3`、`μb1(s)=x−2`、`μc1(s)=x−6` 等。
- **环境与 benchmark**：
  - 使用 Gymnasium 中的五个控制环境：CartPole（离散动作）、Reacher、Pusher、Fetch、Adroit（连续动作）。
  - 选取环境的水平位置成分作为 STL 信号，做归一化与尺度缩放。
  - 移除环境原生奖励，只保留 STL 相关目标；最大回合长度 500 步。
- **对比方法**：
  - **STL-RM**（本文方法）：连续概率转移，CDF 采用裁剪线性函数。
  - **STL-RM (Discrete)**：消融实验，将 CDF 替换为指示函数 `1_{z≥0}`，去除连续鲁棒性信息。
  - **Stacking**：将最近 5、50、500 个观测信号与当前状态拼接作为输入。
  - **Recurrent**：使用一层 256 隐藏单元的 LSTM 学习历史表示。

## 6. 论文的主要结论与发现

- 在 `φpartial` 下，STL-RM 和离散变体均能快速达到满足率为 1 的策略，除 Fetch 环境外基本优于所有基线；STL-RM 的鲁棒性分数通常更高。

- 自动机驱动的奖励设计为无模型 STL 控制综合提供了一条有前景的路径，避免了显式全历史状态增广。

## 7. 优点

- **可扩展记忆机制**：用自动机位置和时钟估值替代完整历史记忆，显著降低状态增广维度，支持完整 STL 而非仅限片段。
