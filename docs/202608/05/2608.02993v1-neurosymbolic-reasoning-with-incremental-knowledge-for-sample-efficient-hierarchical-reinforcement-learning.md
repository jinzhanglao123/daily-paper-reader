## 摘要
在需要长期推理的稀疏奖励环境中，平坦的强化学习代理面临重大挑战。提高样本效率的一种有力方法是将知识融入学习和决策中。在标准的分层强化学习中，知识以固定的、不可更新的形式编码（例如架构选择），并在整个学习过程中保持不变。在固定的分层强化学习中，在获得足够的环境知识之前，利用探索过程中学到的增量知识进行推理是不切实际的，这导致样本效率低下。在本工作中，我们提出了带有增量知识的神经符号分层强化学习：符号高层组件在当前增量知识的可更新表示上执行符号规划（例如使用D*算法），而低层目标条件神经模块通过使用奖励塑形的经验来学习运动原语。在导航任务上的实验表明，融入增量知识显著提高了样本效率。此外，为了在给定先验世界知识的情况下执行最优符号规划，我们开发了信念世界树搜索。代码可在https://github.com/CPS-research-group/ink_bwts获取。

## Abstract
(Flat) Reinforcement Learning (RL) agents face significant challenges in environments with sparse rewards that require long-horizon reasoning. A compelling approach to improve sample efficiency is to incorporate knowledge into learning and decision-making. In standard Hierarchical RL (HRL), knowledge is encoded in a fixed, non-updatable form, such as architectural choices, and remains unchanged throughout learning. With fixed HRL, reasoning with incremental knowledge learned during exploration is impractical before sufficient environmental knowledge is acquired, leading to poor sample efficiency. In this work, we propose neurosymbolic HRL with {\em Incremental Knowledge (InK)}: symbolic high-level components perform {\em symbolic planning} (e.g. using $D^*$) on an updatable representation of current InK, while low-level goal-conditioned neural modules learn motion primitives through experience using reward shaping. Experiments on navigation tasks demonstrate that incorporating InK substantially improves sample efficiency. Additionally, to perform {\em optimal} symbolic planning given {\em prior} knowledge about the world, we develop Belief World Tree Search. The code is available at https://github.com/CPS-research-group/ink_bwts.

- **核心问题**：如何使分层强化学习智能体能够在任务执行过程中动态更新其对环境的认识，并利用这种**增量知识（Incremental Knowledge, InK）** 进行在线推理与重规划，从而大幅提升样本效率，尤其是在连续控制与运动原语结合的场景下。
- **整体含义**：提出一种**神经符号分层强化学习框架（InK）**，高层采用符号规划器（如D*）在可更新的抽象世界模型上规划，低层采用目标条件神经网络执行连续动作，并通过执行反馈闭环更新高层知识。同时针对含有结构先验知识的情景，设计了**信念世界树搜索（BWTS）** 算法，以实现增量知识下的最优平均成本规划。

### 2. 方法论
- **核心思想**：  
  - 高层维护一个**可更新的符号化抽象世界模型** \(M\)，该模型以离散状态图表示，边表示可行转移。  
  - 低层是从原始观测到连续动作的**目标条件神经网络策略**，相当于高层子目标的执行器与环境“传感器”。  
  - 高层规划器依据当前 \(M\) 生成到达最终目标的子目标序列，低层执行子目标并实时监测转移成功/失败；一旦发现与实际执行不一致（如撞墙），则**更新 \(M\) 中的知识**，触发高层重规划（如D*的增量图更新）。  
  - 该循环**消除了传统非增量方法（如SoRB、RGL）必须进行的大规模前期无目标探索**，实现从第一回合开始即进行目标导向行为。

- **增量知识（InK）的形式化**：  
  定义信念世界过程 \(M = (W_0, S, A, (T_W)_{W \in W_0}, C)\)，其中 \(W_0\) 是可能世界的有限集（编码环境的结构先验），\(S\subseteq \mathbb{R}^n\) 为连续状态空间，\(A\) 为动作空间，\(T_W\) 为确定或随机转移函数，\(C\) 为代价（仅目标区域代价为0）。已知历史轨迹 \(\rho\) 可排除某些世界，更新信念集 \(W_\rho\)。策略 \(\pi\) 在真实世界上的期望代价为所有可能世界的平均代价。InK问题的目标是寻找最小化平均成本的策略。

- **符号规划器**：  
  - **D\***：经典的增量路径规划算法，能在环境地图动态变化时高效重规划，但只考虑当前已知图，不利用先验可能世界分布，故在平均意义上可能非最优。
  - **信念世界树搜索（BWTS）**：针对离散符号图设计，维护信念集 \(W_\rho\)。通过构建**决策节点**（选择下一步动作）与**机会节点**（世界是否在该方向存在障碍）的AND-OR树，利用反向归纳和启发式搜索逼近最优平均成本策略。  
    - **节点类型**：决策节点 \((v, W)\) 表示在状态 \(v\) 且信念集为 \(W\) 时选择动作；机会节点 \((v, a, W)\) 表示执行动作 \(a\) 后的不确定结果（墙或无墙），分支为 \((v, W^-)\) 和 \((v', W^+)\)。  
    - **估价与选择**：用一组**策略性rollout策略**（如向不同边界中点前进并按固定方向探测开口）评估叶子节点，代替随机rollout，避免无限循环并稳定估计。采用类似MCTS的UCT规则平衡探索与利用（决策节点用LCB选择动作），机会节点按子节点信念集大小偏置选择以加速大信念集分支的探索。  
    - **反向传播**：机会节点价值为子节点价值的加权平均（权重为信念集基数比），决策节点价值为最小动作价值。  
    - **理论保证**：证明了当迭代次数足够大时BWTS树收敛到完全BWTS树，其策略收敛到InK问题的最优策略。

### 6. 主要结论与发现
1. **InK 显著提升样本效率**：  
   - 在 Point‑Maze 中，从零开始 InK‑D\* 所需步数仅为 RGL 的 3%~8%；训练 75 个目标后，InK 持续优于 RGL 训练后的性能，且在 200 个目标序列下累计节省超过 100,000 环境步。  
   - 在 Ant‑Maze U‑Room 高维任务中，InK（D\* 或 BWTS）同样以远少于非InK的步数到达目标。
2. **BWTS 在有结构先验时表现最优**：  
   - 对于水平/垂直墙集合，BWTS 相比 D\* 节省约 15.7%/9.3% 步数，因为它能利用“仅存在一堵带开口的墙”这一先验设计有效探测策略，避免 D\* 可能走的冤枉路。  
   - 当先验混合水平与垂直墙时，BWTS 优势缩小（仅 2.2%），且计算耗时剧增。  
   - 在物理迷宫中，若提供少量候选迷宫作为先验，InK‑BWTS 比 InK‑D\* 步数减半。
3. **BAMCP 不适合结构约束型先验**：因其假设状态-动作对独立，无法表示“仅存在一个障碍”这类全局依赖，导致 cost 高于 D\* 且方差大、频繁回环。
4. **方法论启示**：神经符号 HRL 结合增量知识，既能利用符号规划的高效推理，又能通过神经网络处理高维感知与控制，在样本效率和最终性能之间取得良好平衡。

### 7. 优点
- **框架新颖且实用**：将经典机器人学中的增量地图更新与重规划思想成功嫁接到神经符号HRL，显著降低了构建全局世界模型的样本成本。

### 8. 不足与局限
- **计算开销**：BWTS 的构建时间随信念世界数量和动作空间增大而急剧上升（\(O(I \times k \times |V| \times |W_0|)\)），在混合先验下 runtime 从约1秒涨至52秒，限制了实时应用。

- **先验依赖性**：BWTS 需要预先定义信念世界集合（如所有单墙+开口组合），当真实环境不匹配该族时，方法可能失效；若完全无先验，BWTS 优势微弱且 runtime 高昂，不如 D* 实用。
