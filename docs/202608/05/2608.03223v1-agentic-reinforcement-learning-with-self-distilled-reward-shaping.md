## 摘要
智能体强化学习使大语言模型智能体能够通过交互进行学习，但稀疏的轨迹级奖励揭示了成功却未指明哪些中间决策应获得贡献。仅训练用的特权技能可通过让相同的冻结策略快照对来自无技能轨迹的固定令牌重新评分，同时以任务匹配的程序技能为条件，提供更密集的监督。然而，现有方法并未在交互步骤间联合校准教师评分，未将教师置信度与实际回报相关联，也未将所得信号整合到原生奖励到优势的构建中。我们提出了基于自蒸馏奖励塑形的智能体强化学习（ADRS），这是一个为多轮语言智能体构建与回报相关联的令牌级贡献的框架。ADRS在每一步内对特权令牌评分进行中心化和归一化，通过基于组内置信度-回报关联的回报关联教师价值优势（TVA）门控对其进行调节，并将门控后的令牌信号融入原生强化学习的贡献构建中。这些组件共同决定了教师偏好什么、这种偏好何时与回报相关，以及它如何进入原生强化学习的贡献路径，同时保持轨迹展开和推理过程无技能。最后，在三个交互基准上的实验表明，ADRS在长周期任务上持续提升性能，增益在强化学习骨干网络、缩减数据设置、未见任务和延长训练中均能保持。为匿名审阅，我们的代码可在以下链接获取：https://github.com/gitrxh/ADRS-arxiv

## Abstract
Agentic reinforcement learning enables LLM agents to learn through interaction, but sparse trajectory-level rewards reveal success without identifying which intermediate decisions deserve credit. Training-only privileged skills can provide denser supervision by allowing the same frozen policy snapshot to rescore fixed tokens from skill-free trajectories while conditioned on task-matched procedural skills. Existing methods, however, do not jointly calibrate teacher scores across interaction steps, relate teacher confidence to realized returns, and integrate the resulting signal into native reward-to-advantage construction. We introduce Agentic Reinforcement Learning with Self-Distilled Reward Shaping (ADRS), a framework for constructing return-associated token-level credit for multi-turn language agents. ADRS centers and normalizes privileged token scores within each step, modulates them with a return-associated Teacher Value Advantage (TVA) gate based on within-group confidence--return association, and incorporates the gated token signal into native RL credit construction. Together, these components determine what the teacher prefers, when that preference is return-relevant, and how it enters the native reinforcement-learning credit path, while keeping rollouts and inference skill-free. Finally, experiments across three interactive benchmarks show that ADRS consistently improves performance on long-horizon tasks, with gains persisting across RL backbones, reduced-data settings, unseen tasks, and extended training. ## 1. 核心问题与整体含义
- **研究动机**：语言智能体在交互式任务（如导航、网络操作）中通常只获得稀疏的轨迹级奖励（成功/失败）。这种反馈虽能反映最终结果，却无法区分长周期多轮交互中哪些中间决策（如某次查询或某个动作）真正贡献了回报，导致令牌级时间信用分配困难，学习效率低下。
- **背景与瓶颈**：训练专用的“特权技能”（procedural skills）能为同一策略快照生成的固定轨迹提供密集的教师评分（teacher scores），但现有方法（如OPSD、Skill-SD、RLSD、SDAR）未能同时解决三个技术挑战：
  1. **分数校准**：不同交互步骤下的原始教师对数概率存在偏移和尺度差异，无法直接跨步比较。
  2. **可靠性估计**：教师置信度高不一定与真实回报相关，高置信度可能仅反映语言规范性而非任务关键性。
  3. **信用整合**：特权信号通常作为独立辅助损失（auxiliary loss），未融入原生强化学习的“奖励→优势→策略”路径，可能导致令牌级更新与组内相对优势（GRPO/GiGPO）不一致。
- **整体含义**：论文提出ADRS（Agentic Reinforcement Learning with Self-Distilled Reward Shaping），旨在将训练专用的程序性技能转化为与回报相关联、可跨步校准的令牌级奖励，并直接注入原生RL信用构造中，同时保证推理时无需任何技能文本。

## 2. 方法论
ADRS是一个三模块框架，作为训练时的信用构造层，位于轨迹收集与策略优化之间：

### 2.1 步骤内相对特权评分（Score Calibration）
- 冻结策略快照分别以普通上下文和技能增强上下文重新计算同一轨迹上每个令牌的对数概率：`ℓT`（特权分数）和`ℓb`（行为分数）。
- 在每个交互步骤内，计算`ℓT`的均值`b_s`，得到中心化分数`q = ℓT - b_s`。
- 对`q`进行缩放归一化（除以该步或序列内的标准差），得到稳健的标准化分值`q̂`，满足步内零和性质（∑q̂ = 0）。这消除了步骤间的整体偏移和离散度差异，使相对偏好可跨步比较。

### 2.2 回报关联的TVA可靠性门控（Reliability Estimation）
- **教师价值优势（TVA）门控**用于衡量教师置信度是否与真实环境回报一致。它不依赖步骤内校准结果，而是使用原始`ℓT`和记录的回报。
- 可选择比较层级：完成级（L2，与GRPO相同组内轨迹对比）或步骤级（L3，与GiGPO的锚点状态匹配）。
- 计算每个比较单元的平均置信度`ℓ̄T`，通过Softmax-like函数得到高置信度权重`α`。
- 定义`d = α_-weighted_mean_return - (1-α)_weighted_mean_return`，其符号与组内置信度-回报协方差一致（命题1）。经过Sigmoid缩放后得到门控值`m`（0~1之间），广播至该单元的所有令牌。
- 当TVA关闭时，`m=1`；组内样本不足时，`m=0.5`。

### 2.3 教师引导的逐令牌优势调制（Credit Integration）
- 计算教师令牌奖励：`rT = η * m * q̂`，其中`η`为教师尺度系数。
- 构造塑形后的令牌奖励：`r̃ = r_base + rT`。
- **双路径信用整合**：
  - **轨迹路径**：将`r̃`求和作为轨迹总分，经过组内标准化得到轨迹优势`A_traj`。由于步内`rT`零和，轨迹总分等于基础奖励总分，保持了环境返回的轨迹排序（命题2）。
  - **令牌路径**：对保存的`rT`进行白化（标准化）得到`ZT`，作为令牌级调制量。
  - 最终令牌级优势：`A_ADRS = A_traj + η * ZT`。此构造在行为策略点处的局部一阶梯度与使用`ZT`作为额外系数的辅助损失更新等价（命题3），确保令牌信号与原生信用路径一致。
- 该优势直接输入GRPO或GiGPO的标准裁剪策略更新，全程无需在推理中使用技能文本。
