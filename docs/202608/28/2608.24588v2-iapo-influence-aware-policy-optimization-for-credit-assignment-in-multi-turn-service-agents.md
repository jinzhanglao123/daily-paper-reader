## 摘要
大型语言模型（LLM）智能体越来越多地通过用户和外部工具的多轮交互来解决长程任务。在这些场景中，相关任务信息往往随时间逐步展开，而非在初始提示中被完全指定。服务智能体使这一挑战尤为具体：用户可能澄清或修改其目标，而工具响应为后续决策提供所需信息。因此，仅凭最终奖励无法表明哪些动作对解决任务做出了贡献。近期方法依赖来自其他轨迹或重采样续写的比较证据，或依赖单独构建的步骤级学习信号，来改进信用分配。然而，一个已完成的 rollout 已经记录了信息和错误如何在智能体动作之间流动。我们提出影响力感知策略优化（IAPO），它将每个 rollout 表示为可训练智能体动作上的类型化影响依赖图，并以用户和工具观察作为证据。IAPO 将支持-使用和失败-使用结构转换为路由权重，重新分配同一轨迹级优势。基于 Qwen3-4B 和 Qwen3-8B 的实验表明，在三个服务智能体基准（τ²-Bench、UserBench 和 AgentChangeBench）上，其性能优于多轮强化学习（RL）基线。BFCL-v4 Multi-Turn 进一步表明，这些提升并未损害多轮函数调用性能。本研究推进了对多轮用户交互中信用分配的理解，并提供了一种从稀疏结果反馈训练服务智能体的原则性方法。

## Abstract
Large Language Model (LLM) agents increasingly solve long-horizon tasks through multi-turn interactions with users and external tools. In these settings, relevant task information often unfolds over time rather than being fully specified at the initial prompt. Service agents make this challenge especially concrete: users may clarify or revise their goals, while tool responses provide information needed for subsequent decisions. Thus, a final reward alone cannot indicate which actions contributed to resolving the task. Recent methods rely on comparative evidence from other trajectories or resampled continuations, or on separately constructed step-level learning signals, to refine credit. However, a completed rollout already records how information and errors flow between agent actions. We introduce Influence-Aware Policy Optimization (IAPO), which represents each rollout as a typed influence-dependency graph over trainable agent actions, with user and tool observations serving as evidence. IAPO converts support-use and failed-use structure into routing weights that redistribute the same trajectory-level advantage. Experiments with Qwen3-4B and Qwen3-8B demonstrate superior performance over multi-turn reinforcement learning (RL) baselines across three service-agent benchmarks: ${τ^2}$-Bench, UserBench, and AgentChangeBench. BFCL-v4 Multi-Turn further shows that these gains do not compromise multi-turn function-calling performance. This work advances the understanding of credit assignment in multi-turn user interactions and provides a principled approach to training service agents from sparse outcome feedback.

## 1. 论文的核心问题与整体含义

- **研究动机**：多轮服务智能体通过用户澄清、目标修改、工具返回等交互逐步获得任务信息，而非初始提示一次性给定。最终结果奖励无法区分中间动作的真实贡献，即“演化状态下的信用分配”问题。
- **现有局限**：GRPO 等组级 RL 方法将同一轨迹级优势广播到所有 token，无法区分关键动作与冗余/错误动作。现有细粒度信用分配方法往往需要跨轨迹对比、可重置环境、额外评分通道或教师模型，在真实用户–工具对话中难以满足。
- **核心思想**：已完成的 rollout 中已经记录了信息如何被下游动作使用、错误如何传播。IAPO 希望仅利用单条 rollout 内部已实现的依赖结构，将同一轨迹级优势在动作间重新分配，而不改变最终奖励、采样流程和优化接口。

## 2. 论文提出的方法论

- **影响依赖图构建**：
  - 对轨迹中每个可训练动作 \(a_i\)，构建图 \(G_\tau = (V_\tau, E^+_\tau, E^-_\tau)\)。
  - \(E^+\) 为“支持–使用”边：下游动作消费了上游动作提供或引出的信息。
  - \(E^-\) 为“失败–使用”边：下游动作复用上游错误输出、无效输出，或因上游错误而回退。
  - 引入错误指示器 \(e_i\in\{0,1\}\)，标记工具/模式/运行时/规则失败或用户显式拒绝；目标修订不算错误，除非拒绝前序动作。
- **边接受条件**：需要同时满足必要性、显式绑定、来源优先级三个条件，避免仅因主题相似建立边。
- **图特征**：
  - 支持特征：\(\phi^+_i = \log(1 + d^+_i + d^{in}_i)\)，其中 \(d^+_i\) 是下游支持使用者数量，\(d^{in}_i\) 是上游支持来源数量。
  - 错误特征：\(\phi^-_i = \log(1 + e_i(1 + d^-_i + d^{in}_i))\)，仅在 \(e_i=1\) 时非零，综合错误本身、失败使用下游数量和支持来源。
- **从特征到有界权重**：
  - 对特征做长度加权标准化，经 clip 后通过指数映射归一化，得到每个动作的乘性权重 \(m_i\)，默认长度加权均值为 1。
- **符号条件路由**：
  - 正优势 rollout：\(w^+_i \propto L_i m^+_i \exp(-\beta_+\psi^-_i)\)，其中 \(\psi^-_i\) 是错误证据高于均值的部分，用于抑制“后来被修复的出错步骤”的正向信用。
  - 负优势 rollout：\(w^-_i = m^-_i\)，将负优势集中到有可观察错误的步骤。
  - 最终 token 优势：\(A_{i,\ell}=\hat{A}_\tau w_i\)。
- **理论性质**：质量守恒、均匀回退、符号保持、优化接口保持。冻结标注器（如 Qwen3-32B）提取依赖图并缓存，不参与策略梯度更新。

- **主结果**：IAPO 在两个模型规模上均优于 GRPO 及对比基线。8B 模型在 \(\tau^2\)-Bench 上较 GRPO 提升 \(+12.57\) 个百分点（29.61→42.18），UserBench \(+4.61\)，AgentChangeBench \(+4.41\)。
- **泛化性**：仅用 \(\tau^2\)-Bench 训练，IAPO 在所有其他基准 split 上仍有提升，尤其 telecom 分域提升最大（+18.19 pp）。
- **保留函数调用能力**：BFCL-MT 与 GRPO 接近持平，8B 为 39.36 vs 39.04，4B 略有提升，说明没有损害函数调用能力。

- **消融结论**：
  - 支持使用与错误传播都提供独立有用信号；
  - 小幅度错误折扣（\(\beta_+=0.05\)）最优，过大反而下降；
  - clipping \(c=0.25\) 在域内与迁移间取得最佳平衡；
  - 负分支应从错误传播出发，而非支持中心性；
