## 摘要
大型语言模型（LLM）智能体越来越多地通过与用户和外部工具的多轮交互来解决长程任务。在这些场景中，相关任务信息往往随时间逐步展开，而非在初始提示中完全指定。服务智能体使这一挑战尤为具体：用户可能会澄清或修改目标，而工具响应则为后续决策提供所需信息。因此，仅凭最终奖励无法表明哪些动作对任务解决做出了贡献。近期方法依赖来自其他轨迹或重采样续段的比较证据，或依赖单独构建的步级学习信号来细化信用分配。然而，一次完整的执行过程（rollout）已经记录了信息与错误如何在智能体动作之间流动。我们提出了影响力感知策略优化（IAPO），该方法将每次执行过程表示为一个在可训练智能体动作上的类型化影响依赖图，并以用户和工具观测作为证据。IAPO 将支持使用和失败使用的结构转换为路由权重，以重新分配同一轨迹级别的优势。在 Qwen3-4B 和 Qwen3-8B 上的实验表明，在三个服务智能体基准测试——{τ^2}-Bench、UserBench 和 AgentChangeBench——上，其性能优于多轮强化学习（RL）基线。BFCL-v4 Multi-Turn 进一步表明，这些提升并未牺牲多轮函数调用性能。这项工作推进了对多轮用户交互中信用分配的理解，并提供了一种基于稀疏结果反馈训练服务智能体的原则性方法。

## Abstract
Large Language Model (LLM) agents increasingly solve long-horizon tasks through multi-turn interactions with users and external tools. In these settings, relevant task information often unfolds over time rather than being fully specified at the initial prompt. Service agents make this challenge especially concrete: users may clarify or revise their goals, while tool responses provide information needed for subsequent decisions. Thus, a final reward alone cannot indicate which actions contributed to resolving the task. Recent methods rely on comparative evidence from other trajectories or resampled continuations, or on separately constructed step-level learning signals, to refine credit. However, a completed rollout already records how information and errors flow between agent actions. We introduce Influence-Aware Policy Optimization (IAPO), which represents each rollout as a typed influence-dependency graph over trainable agent actions, with user and tool observations serving as evidence. IAPO converts support-use and failed-use structure into routing weights that redistribute the same trajectory-level advantage. Experiments with Qwen3-4B and Qwen3-8B demonstrate superior performance over multi-turn reinforcement learning (RL) baselines across three service-agent benchmarks: {τ^2}-Bench, UserBench, and AgentChangeBench. BFCL-v4 Multi-Turn further shows that these gains do not compromise multi-turn function-calling performance. This work advances the understanding of credit assignment in multi-turn user interactions and provides a principled approach to training service agents from sparse outcome feedback.

## 1. 论文的核心问题与整体含义

- **研究背景**：大型语言模型（LLM）智能体在多轮服务场景中，任务信息往往不是初始提示中完全给定的，而是随时间逐步展开：用户会澄清或修改目标，工具返回结果决定后续动作是否合法或有用。
- **核心问题**：最终奖励是稀疏的、轨迹级别的，无法自动说明中间动作分别对成功或失败做出了多少贡献，即“演化状态下的信用分配”问题。
- **现有方法的不足**：
  - 跨轨迹方法需要可比较的重复状态、可重置环境或分支式采样，但自由形式用户/工具对话通常不具备这些条件。
  - 单独构建步骤信号的方法需要额外评分器、教师模型或特权信息上的 critic，可能偏离任务完成本身。
- **本文切入点**：一个已完成的 rollout 内部已经记录了信息流和错误传播结构。IAPO 直接利用这种已实现依赖，在不改变奖励、采样、group normalization 和 clipped loss 实现的前提下，将轨迹级优势重新分配到动作 token 上。

## 2. 论文提出的方法论

- **核心思想**：将每条 rollout 表示为可训练动作上的类型化影响依赖图 `Gτ = (Vτ, E+τ, E−τ)`，用户与工具观测只作为证据，不接收策略梯度。
- **两类边**：
  - **支持使用边 `i →+ j`**：动作 `aj` 使用了动作 `ai` 提供或引出的信息，注释类型为 `input` 或 `success_utilization`。
  - **失败使用边 `i →− j`**：动作 `aj` 重复了 `ai` 的显式错误、使用其无效输出，或因此回退，注释类型为 `failed_utilization`。
- **边接受条件**：必须同时满足必要性、显式绑定、来源优先级三个条件；仅主题相似或抽象相似不够。
- **图特征**：
  - 支持特征：`φ+_i = log(1 + d+_i + d_in_i)`，其中 `d+_i` 是 `ai` 的后继支持消费者数量，`d_in_i` 是从直接用户轮次或前置支持边获得的信息数量。
  - 错误特征：`φ−_i = log(1 + e_i(1 + d−_i + d_in_i))`，其中 `e_i` 是显式错误指示器；只有发生可观测错误时才非零。
- **从特征到有界权重**：对特征做长度加权标准化，clip 到 `[-c, c]`，再通过指数和长度加权重归一化，得到长度平均为 1 的权重 `m+_i` 和 `m−_i`。
- **符号条件路由**：
  - **正优势 rollout**：`w+_i = L m+_i exp(−β+ ψ−_i) / Σ_j L_j m+_j exp(−β+ ψ−_j)`，其中 `ψ−_i = φ−_i − 平均错误特征`。`β+` 控制对“曾出错但后续被修复”的动作扣减多少信用。
  - **负优势 rollout**：`w−_i = m−_i`，即主要依据可观测错误传播分配 blame，保守地不使用支持中心性。
- **最终优势**：每个动作及其 token 的优势为 `Ai,ℓ = \hat A_τ w_i`，替代 GRPO 对每个 token 的均匀广播。
- **性质保证**：质量守恒、均匀回退、符号保持、优化接口保持。

## 6. 论文的主要结论与发现

- **性能提升**：在 Qwen3-8B 上，IAPO 将 τ²-Bench 的 domain-macro pass¹ 从 GRPO 的 29.61% 提升到 42.18%，提高 12.57 个百分点；UserBench 提升 4.61 个百分点；AgentChangeBench 提升 4.41 个百分点。
- **函数调用不衰退**：BFCL-v4 Multi-Turn 分数相对 GRPO 基本持平，8B 为 39.36% vs 39.04%，说明提升不是通过牺牲通用函数调用能力获得的。
- **延迟状态使用收益最大**：τ²-Bench telecom 提升 18.19 个百分点，说明信息需要等到后续澄清才被使用的场景，从 IAPO 中获益最多。
- **路由权重显著非平坦**：正权重 `w+` 标准差 0.222，范围 0.637–1.505，86.5% 的步骤偏离均匀信用超过 10%。
- **正负优势导电路径不同**：正优势使用支持使用 + 错误折扣，负优势使用可观测错误传播。
- **跨标注器稳定**：6 个不同冻结标注器的边 F1 平均 0.87，路由权重的 Spearman 相关较高，说明对默认 Qwen 标注器不敏感。

## 7. 优点

- **无需额外训练信号**：不使用额外奖励模型、critic、教师模型或反事实连续采样，只利用已完成 rollout 内部的依赖结构。
- **理论性质清晰**：给出质量守恒、均匀回退、符号保持和优化接口保持等性质，说明引入路由不会破坏 GRPO 更新结构。
- **与 GRPO 严格对照**：除 token 优势映射外训练协议一致，能较干净地隔离变量。
- **消融分析到位**：分别检验支持使用、错误证据、clip 约束和不同标注器，验证设计选择不是偶然。
- **跨领域泛化良好**：仅在 τ²-Bench 上训练，却在 UserBench、AgentChangeBench 上持续提升，说明学到的信用分配能力可迁移。
- **标注器稳健性高**：跨模型一致性实验减轻了对单一 LLM 标注器的担忧。

## 8. 不足与局限

- **依赖冻结 LLM 标注器**：虽然跨模型一致性较好，但影响图仍来自启发式标注，可能引入噪声或系统性偏差；在极端开放域对话中可能失效。
- **只覆盖服务代理领域**：训练和评估集中于服务类任务，是否适用于更广泛的多轮推理、编程或具身智能体任务尚未验证。
- **训练数据规模较小**：仅使用 178 个 τ²-Bench 任务，可能

- **未与过程奖励模型类方法直接对比**：虽然与 GiGPO、InfoPO 等信用分配方法比较，但缺少与基于过程奖励模型（PRM）或显式步骤评估器的在线方法在同一训练预算下的对照，无法完全排除“过程监督会更好”的可能性。  
- **模型和任务类型覆盖有限**：实验仅针对 Qwen3-4B/8B 和特定服务代理基准，未在其他模型家族、更大规模模型或非服务类多轮任务上测试，结论的适用范围需要谨慎看待。  
- **负优势分配依赖显式错误信号**：对于没有可观测错误但实际导致失败的隐式错误（如信息缺失、误导性但未报错的输出），`w− = m−` 可能无法有效归因，未来可探索结合隐式不确定性或反事实推理的扩展。
