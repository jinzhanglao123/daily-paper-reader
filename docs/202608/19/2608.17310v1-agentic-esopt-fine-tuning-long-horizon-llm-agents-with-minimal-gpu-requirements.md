## 摘要
强化学习（RL）在单轮 LLM 微调中已展现出潜力。然而，长程智能体推理引入日益分支的交互和稀疏奖励，暴露出 RL 的若干局限：其基于反向传播的训练栈过于沉重，难以微调更大的 LLM；更长的轨迹使 RL 中的信用分配显著更难。本文认为演化策略（ES）可能是微调长程 LLM 智能体的更佳选择。与智能体 RL 相比，ES 具有三个关键优势：1）模型可扩展性：ES 仅需极少、推理级的 GPU 内存即可进行全参数优化，使微调大型 LLM 成为可能。2）灵活性：其轻量、黑盒反馈接口使 ES 微调易于与提示空间演化（如技能优化与测试时计算）组合；3）长程可扩展性：ES 在轨迹层面进行参数归因，无需跨时间步分解奖励，因此随着轨迹长度增加，其可扩展性优于智能体 RL。基于这一见解，我们提出 Agentic ESOpt，一个面向灵活参数—上下文协同演化的全参数智能体微调框架。在每一步中，Agentic ESOpt 在当前 LLM 参数周围采样扰动，用奖励评估所得智能体，并施加在线奖励加权更新。为改善探索—适应权衡，Agentic ESOpt 进一步引入扰动尺度 σ 的余弦衰减调度。在 WebArena-Lite 上，Qwen-3.5-27B 的全参数优化将 No Skill 基线提升了 6.69%。在测试时自动启发式设计中，Agentic ESOpt 进行在线提示—参数协同演化，在 36 个设置中的 28 个上优于其匹配基线。

## Abstract
Reinforcement Learning (RL) has been promising in single-turn LLM fine-tuning. However, long-horizon agentic reasoning introduces increasingly branching interactions and sparse rewards, exposing several limitations of RL: its heavyweight backpropagation-based training stack makes it impractical to fine-tune larger LLMs, and longer-horizon trajectories make credit assignment in RL substantially harder. This paper argues that evolution strategies (ES) can be a better choice for fine-tuning long-horizon LLM agents. Compared with agentic RL, ES offers three key advantages: 1) Model Scalability: ES enables full-parameter optimization with only minimal, inference-level GPU memory, making it possible to fine-tune large LLMs. 2) Flexibility: its lightweight, black-box feedback interface makes ES fine-tuning easy to compose with prompt-space evolution (e.g., skill optimization & test-time compute); and 3) Long-Horizon Scalability: ES performs trajectory-level parameter attribution without decomposing rewards across horizons, yielding better scalability than Agentic RL as the horizon length grows. Based on this insight, we propose Agentic ESOpt, a full-parameter agentic fine-tuning framework tailored to flexible parameter--context co-evolution. At each step, Agentic ESOpt samples perturbations around the current LLM parameters, evaluates the resulting agents with rewards, and applies an online reward-weighted update. To improve the exploration--adaptation trade-off, Agentic ESOpt further introduces a cosine decay schedule of the perturbation scale $σ$. On WebArena-Lite, full-parameter optimization of Qwen-3.5-27B improves the No Skill baseline by 6.69%. In test-time automatic heuristic design, Agentic ESOpt performs online prompt--parameter co-evolution, improving its matched baseline in 28 of 36 settings.

# Agentic ESOpt 论文总结

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：长程（long-horizon）LLM 智能体微调中，强化学习（RL）面临两大核心困难：
  - **训练资源重**：反向传播需要存储激活、优化器状态，全参数微调大模型（如 27B）在有限 GPU 上几乎不可行。
  - **信用分配难**：长轨迹、分支交互、稀疏终局奖励使得把轨迹级奖励分解到每个动作变得困难，回合数越长，RL 估计方差近似线性增长。
- **核心主张**：进化策略（ES）更适合长程智能体微调，因为它：
  - **模型可扩展性**：仅需推理级 GPU 内存即可全参数优化。
  - **灵活性**：黑盒标量奖励接口容易与提示空间方法（技能优化、测试时计算）组合。
  - **长程可扩展性**：在轨迹层面直接对参数扰动做归因，不跨时间步累积分数，方差不随 horizon 显式增长。
- **提出方法**：Agentic ESOpt，一个全参数、无反向传播的 ES 框架，支持训练时微调与测试时在线协同演化。

## 2. 论文提出的方法论
- **核心思想**：在当前参数 θ 周围采样全参数高斯扰动 ϵ，对每个扰动后的智能体在环境中执行轨迹并得到标量奖励 R，再用奖励加权平均扰动方向更新参数，全程只需前向传播。
- **关键公式**（文字说明）：
  - 高斯平滑目标：  
    `Jσ(θ;c) = E_{ϵ∼N(0,I)}[J(θ+σϵ;c)]`
  - ES 伪梯度：  
    `∇θJσ(θ;c) = (1/σ) E_ϵ[J(θ+σϵ;c)·ϵ]`
  - 实际更新采用群体内 z-score 归一化奖励，省略显式 `1/σ`，以 `α` 作为有效学习率：  
    `θ_{t+1} = θ_t + (α/G) Σ_i R̂_i ϵ_i`，其中 `R̂_i = (R_i - μ_R)/(s_R+ε)`。
- **扰动尺度余弦衰减**：  
  `σ_t = σ_T + (σ_0 - σ_T)·(1+cos(πt/T))/2`  
  训练时保留非零 `σ_T` 以维持平滑正则化与探索；测试时 `σ_T` 衰减到 0，减小目标偏差。
- **提示—参数协同演化**：  
  同一批轨迹可同时用于技能提取、提示更新和 ES 参数更新，交替执行：
  - `θ_{t+1} = U_ES(θ_t; c_t, D_t)`
  - `c_{t+1} = U_c(c_t; D_t)`
- **实现细节**：只存储噪声种子，用原位加减法施加/撤销扰动，因此 GPU 内存需求与推理相同；G 为种群大小，每个方向可在多个任务上评估。

  去掉 σ 衰减或让 σ_T=0 均导致性能下降，说明该调度在探索—适应权衡中起关键作用。

- **方法简单、可扩展**：仅需前向传播和黑盒标量奖励，GPU 内存与推理相同，显著降低大模型微调门槛。
- **理论支撑清晰**：提供了高斯平滑偏差证明和长程信用分配的方差分析，解释了为什么 ES 在长 horizon 下更具优势。

- **实验设计较规范**：匹配 FLOPs、统一评价协议、多任务覆盖、多次重复运行，增强了结论可信度。
- **开源与可复现性**：提供了 GitHub 仓库、详细超参数配置、prompt 与技能内容。

## 8. 不足与局限
- **评估成本权衡**：ES 用更多独立环境评估替代反向传播；当环境评估本身非常昂贵或不可大规模并行时，ES 的性价比可能下降。
- **超参数敏感性**：引入了 σ_0、σ_T、α 等新超参数，尽管论文报告了跨任务较一致的取值，但调参成本仍可能高于固定 RL 配方。
- **短 horizon 任务不占优**：在 H*≤10 的 Sudoku 上，ESOpt 不如 PPO 或 GRPO，说明其优势主要在长程、稀疏奖励场景。
- **缺少更大模型和真实 RL 对照**：WebArena 实验未直接对比同规模的 GRPO/PPO，削弱了该场景下的因果结论。
- **种群缩放定律尚属初步**：4B/9B 敏感性发现基于有限数据，未建立系统性 scaling law，也未在更大模型上验证。
- **未来工作指向**：需要自动化 σ 调度、支持量化 ES、更紧密的技能—参数

协同演化机制、跨环境鲁棒性验证，以及在更大规模模型和更多真实智能体任务上的泛化验证。
