## 摘要
面向用户的工具智能体必须在用户目标跨多轮展开时协调对话与工具使用。然而，交互式强化学习通常将每次 rollout 压缩为一个终止奖励，从而对有效的需求澄清、错误与后续修复分配相同的功劳。下一轮用户话语不仅仅是上下文：它还提供了关于前一个用户到用户片段的、带噪声且时间上局部的证据。我们提出反馈感知功劳分配（FACA），该方法将每次反应与该片段对齐，推导出局部归一化的反应优势，并将其添加到经过验证的终止结果优势上，而无需额外的 critic 或 rollout。与在模拟器、可见对话、初始化、rollout 和优化设置上均保持一致且仅使用结果的 Interactive GRPO 对照相比，FACA 在 8B 和 14B 规模上，将三次独立训练运行的九域 τ-family 平均指标分别提高了 5.91 和 10.22 个百分点。提升主要集中在 Telecom 领域；在 8B 规模下，随机化反应极性会消除 Telecom 上的提升。相同排序在 Pare-Bench 和 Co-Gym 上的零样本设置中同样成立。这些结果表明，下一轮用户反应为改进多轮用户交互智能体提供了可操作的局部功劳。

## Abstract
User-facing tool agents must coordinate dialogue and tool use as user goals unfold over multiple turns. Yet interactive reinforcement learning typically reduces each rollout to a terminal reward, assigning the same credit to effective elicitation, errors, and later repair. The next user turn is more than context: it also provides noisy, temporally local evidence about the preceding user-to-user segment. We introduce \textbf{F}eedback-\textbf{A}ware \textbf{C}redit \textbf{A}ssignment (\textsc{FACA}), which aligns each reaction with that segment, derives a locally normalized reaction advantage, and adds it to verified terminal outcome advantage without an extra critic or rollout. Against an outcome-only Interactive GRPO control matched in simulator, visible dialogue, initialization, rollout, and optimization, \textsc{FACA} improves the nine-domain $τ$-family average across three independently trained runs by 5.91 and 10.22 percentage points at 8B and 14B, respectively. Gains concentrate in Telecom; at 8B, randomizing reaction polarity removes the Telecom gain. The same ordering holds zero-shot on Pare-Bench and Co-Gym. These results demonstrate that next-turn user reactions provide actionable local credit for improving multi-turn user-interacting agents.

## 1. 论文的核心问题与整体含义

- **研究背景**：面向用户的工具智能体需要在多轮对话中协调语言交互、工具调用和用户决策，任务目标往往在交互过程中逐步澄清，用户是主动参与者而非静态输入。
- **核心问题**：交互式强化学习通常将整段多轮 rollout 压缩为一个终端奖励（如任务是否成功），导致“有效的需求澄清”“错误动作”和“后续修复”获得完全相同的功劳，无法进行细粒度信用分配。
- **整体含义**：下一轮用户话语不仅是下一步决策的上下文，也是关于前一个“用户到用户（U2U）片段”的、带噪声且时间上局部的反馈信号。有效利用这一信号，可以在保持最终任务目标为核心的同时，提供更细粒度的过程级信用。

## 2. 论文提出的方法论：FACA

- **核心思想**：将下一轮用户反应（utterance + 私有策略元数据）作为前一个 U2U 片段的局部证据，将其转化为局部过程优势，并与终端结果优势相加，从而实现更精细的信用分配。
- **关键概念**：
  - **U2U 片段（user-to-user segment）**：两个相邻用户轮次之间，智能体可能产生的多段语言回复、工具调用和工具结果。
  - **私有反应策略**：冻结的用户模拟器在每次回复时同时输出可见 utterance 和不可见的私有策略标签（如 `confirm`、`ask_clarification`、`change_mind` 等），FACA 只使用后者构造信用，不暴露给智能体。
  - **三元极性映射**：将私有策略映射为 `+1`（进展一致，如 confirm / close / reveal-piece）、`0`（模糊或无效）和 `-1`（摩擦一致，如 ask-clarification / challenge-solution / change-mind）。
- **算法流程（文字说明）**：
  1. 对每个 prompt，采样 K 条完整的多轮交互 rollout，并获得经过验证的终端奖励 \(R_k \in \{0,1\}\)。
  2. 对所有 rollout 计算轨迹级结果优势 \(A^o_k\)，即终端奖励在 prompt 内做标准化（z-score）。
  3. 对每个 U2U 片段，对齐其紧邻的下一轮用户反应，并映射为三元极性 \(f_{k,q}\)。
  4. 在同一 prompt 且同 U2U 序号的局部比较组内，对反应极性做标准化，得到过程优势 \(A^p_{k,q}\)。
  5. 将两者线性相加：\(A_{k,q} = A^o_k + \lambda A^p_{k,q}\)，默认 \(\lambda = 0.5\)，并广播到该 U2U 片段内的所有可训练 token。
  6. 训练时使用 PPO 风格的 clipped importance ratio，仅更新智能体的语言和工具调用 token，用户话语与原始工具结果被 mask。
- **无额外开销**：整个过程不需要学习 critic、不需要额外 rollout，也不需要向智能体暴露反应标签；改变仅在信用分配层面，未改变模拟器、可见对话、初始化、rollout 或优化器。

## 6. 论文的主要结论与发现

- **主结果**：在九域 τ-family 均值上，FACA 相较 outcome-only Interactive GRPO 在 8B 提升 5.91 个百分点，在 14B 提升 10.22 个百分点；按训练种子逐一匹配，所有 6 对运行均保持正增益。
- **域间差异**：提升主要集中在 Telecom，四个 Telecom scale–benchmark 单元均大幅领先；但在部分 Retail 域出现轻微倒退，说明不是普遍的域优势。
- **消融结论**：
  - 时间对齐很重要：将反应向前移一位（Shifted）会抹去增益。
  - 反应语义很重要：随机化反应极性会抹去 Telecom 增益；仅保留 token 级变化不够。
  - λ=0.5 优于 λ=0.1 和负 λ，表明反应信用是辅助信号而非替代目标。
- **零样本迁移**：FACA 在 Pare-Bench 和 Co-Gym 上保持对 outcome-only 对照的优势，但 Pare-Bench 绝对值较低，Co-Gym Travel 域出现轻微回归。
- **机制解释**：用户反应在 Telecom 等“控制频繁交替、用户可执行设备侧操作并反馈结果”的场景中更具信息量；反应的“可观察性”比交互长度更关键。

## 7. 优点

- **极低的额外成本**：利用现有模拟器已经生成的私有反应元数据，不需要额外 critic、额外 rollout 或可见标签，即可实现更细粒度的信用分配。
- **严格的对照实验**：与 outcome-only Interactive GRPO 在初始化、数据、rollout、优化器、horizon 等多个维度完全匹配，能够较干净地隔离信用分配的影响。
- **多维度验证**：不仅报告平均分数，还进行消融、零样本迁移、训练信号动力学和轨迹级审计，证据链较完整。
- **对“下一用户轮次”的反思**：将用户反应视为局部证据而非纯上下文，为交互式强化学习提供了一种实用的中间监督思路。

## 8. 不足与局限

- **依赖冻结模拟器的私有元数据**：FACA 需要用户模拟器提供私有策略标签，这些标签是启发式构造的，可能存在误分类；论文未证明可以从纯可见话语中可靠提取等价信号。
- **模型与模拟器覆盖有限**：仅评估 Qwen3-8B/14B 和 DeepSeek-V4-Flash 冻结用户模拟器，未跨模拟器家族、不同架构或真实用户验证。
- **评估随机性未被充分区分**：每个 checkpoint 只评估一次，run-level 标准差可能混合了训练和评估的随机性；零样本结果缺乏不确定性区间。
- **域上并非普遍改善**：Retail 等部分域出现倒退，Co-Gym Travel 也略有下降，说明反应信用并非对所有任务都有效。
- **奖励黑客风险未完全消除**：λ 上限设为 0.5 可抑制代理优势主导，但模拟器偏差或反馈误分类仍可能带来一定风险。
- **单任务案例解释力有限**：Telecom 轨迹案例只是单一任务，不能单独用于因果归因。
